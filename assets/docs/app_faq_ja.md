# ウォークスルー

## フェーズ 1: ファームウェアのキャッシュ
1.  **インターネットに接続する:** 携帯電話がインターネット（例：自宅のWi-Fiまたはモバイルネットワーク）に接続されていることを確認します。
2.  **ファームウェアマネージャーを開く:** アプリ内でファームウェアマネージャーに移動します。
3.  **リリースをダウンロードする:** 目的のExpressLRSリリースの隣にあるダウンロードアイコンをタップします。これにより、必要なファームウェアターゲットとハードウェア定義が携帯電話に安全にキャッシュされ、100%オフラインで使用できるようになります。

## フェーズ 2: デバイスへの接続
1.  **デバイスの電源を入れる:** ExpressLRS Receiver (RX) または Transmitter (TX) の電源を入れます。
2.  **ホットスポットを待つ:** デバイスがWi-Fiホットスポットモードに入るのを待ちます（LEDの高速点滅で示されます）。
3.  **ホットスポットに接続する:** 携帯電話のWi-Fiをパスワード`expresslrs`を使用して`ExpressLRS RX`または`ExpressLRS TX`ネットワークに接続します。
    *   **注:** ELRS Mobileは強制ルーティングをネイティブに処理し、携帯電話がサイレントに5G/LTEに戻ることを防ぎます。

## フェーズ 3: ファームウェアのフラッシュ
1.  **フラッシュデバイスに移動する:** メインのダッシュボードから、**フラッシュデバイス**を選択します。
2.  **ターゲットの選択:** 階層型ドロップダウンを使用して、ベンダーと特定のハードウェアターゲットを選択します。
3.  **バージョンの選択:** オフラインリポジトリから利用可能なファームウェアバージョンを選択します。
4.  **設定とプロファイル:** カスタム認証情報をロードするために、**フラッシュプロファイル**（例：「My Quads」、「Race Spec」）を選択または作成します。アプリケーションは、Wi-Fi SSID、Wi-Fi Password、Binding Phrase、Regulatory Domain、およびAuto-On intervalsをこれらの名前付きプロファイルに保持するため、異なるセットアップを切り替える際に再入力する必要はありません。
5.  **ビルドとフラッシュ:** **FLASH**をタップします。システムはバイナリにローカル認証情報をパッチし、アップロードします。
    *   **重要:** 成功確認とデバイスのLEDが点滅を再開するまで常に待ち、それからプラグを抜いてください！

# FAQ

## ファームウェアをフラッシュするのにインターネット接続や携帯電話サービスは必要ですか？
いいえ。ELRS Mobileは**100%オフラインフラッシュ**機能を備えています。以前に自宅のWi-Fiでファームウェアマネージャー経由でファームウェアバージョンをダウンロードしていれば、アプリはファームウェアを完全にオフラインで動的に組み立ててフラッシュできます。

## フラッシュプロファイルとは何ですか？また、どのように使用しますか？
フラッシュプロファイルを使用すると、複数のフラッシュ設定（例：「My Quads」、「Stock / Factory Reset」、「Race Spec」）を保存して切り替えることができます。各プロファイルは、独自のBinding Phrase、Wi-Fi SSID、Wi-Fi Password、Regulatory Domain、およびWi-Fi Auto-On Intervalを安全に保存します。

使用方法：
1.  **Configuration Options**カード内の「Flashing Profile」ドロップダウンの隣にある**+**（追加）アイコンをタップします。
2.  新しいプロファイルに名前を付け、設定をカスタマイズします。編集は即座に自動保存されます。
3.  ドロップダウンから任意のプロファイルを選択すると、すべてのパラメーターが自動的に入れ替わります。
4.  プロファイルを削除するには、そのプロファイルを選択し、ゴミ箱/削除アイコンをタップします（1つを削除するには、少なくとも2つのプロファイルが必要です）。

## ESP8285レシーバーをフラッシュすると「Not enough space」エラーが表示されます。
ESP8285チップ（多くのAIOボードに見られるものなど）は、合計で1MBの物理ストレージしかありません。Wi-Fi経由でメジャーリリース（例：3.xから4.x）に直接アップデートすると、現在実行中のファームウェアと一緒に受信ファイルを展開するにはファイルが大きすぎるため、デュアルパーティションスペースが不足する可能性があります。

**解決策：**まず、レシーバーを中間バージョン（例：**3.6.3**）にフラッシュします。より軽量な3.6.3ファームウェアが実行されると、目的の4.0ターゲットに正常にフラッシュするための十分なパーティションスペースが確保されます。あるいは、設定で**Expert Mode**を有効にし、ビルドされたバイナリをローカルに保存して、有線Betaflight Passthrough接続経由で手動でフラッシュすることもできます。

## ラジオ用のExpressLRS Luaスクリプトはどこで見つけられますか？
ELRS Mobileには、ユニバーサルでバージョンに依存しないLuaスクリプトが内蔵されています！入手するには：
1.  **Settings**に移動し、**Expert Mode**をオンにします。
2.  **Export ELRS Lua Script**をタップします。
3.  これにより、`elrs.lua`が携帯電話のローカルストレージに直接保存されます。ラジオの電源を入れ、USB経由で携帯電話に接続し、ラジオで「USB Storage」モードを選択し、携帯電話のファイルマネージャーを使用してファイルを`SCRIPTS/TOOLS`フォルダーに転送します。

**注:** 新しいスクリプトを使用する前に、ラジオのSDカードから以前のelrs.luaスクリプト（例：elrs_v2.lua、elrs_v3.luaなど）を削除する必要があります。

## フラッシュが失敗し、デバイスが応答しなくなった場合はどうすればよいですか？
フラッシュが失敗した後にデバイスが応答しない場合は、簡単に復旧できます：
1.  デバイスのBOOTボタンを押しながらUSB経由で接続し、ブートローダーモードに入ります。
2.  コンピューターとELRS Web Flasherを使用して、有線USB/UART接続経由でデバイスを再フラッシュします。
3.  Wi-Fi対応デバイスの場合、BOOTを保持することもできます。

**注:** リソースタブに、この方法を示すビデオリンクがあります。

## ファームウェアファイルをフラッシュせずに携帯電話に保存できますか？
はい。**Settings**に移動し、**Expert Mode**を有効にすることで、組み立てられたファームウェアバイナリをOver-The-Air (OTA) で即座にフラッシュするのではなく、モバイルデバイスのローカルストレージに直接保存する機能が解除されます。

これは、専用のハードウェアプログラマー（STLinkやFTDIアダプターなど）を使用してデバイスを手動でフラッシュしたい場合に特に役立ちます。

## 「Target Mismatch」エラーが表示されます。どうすればよいですか？
ターゲット不一致エラーは、アプリで選択したハードウェアターゲットがデバイスで現在実行されているファームウェアのターゲットと一致しない場合に発生します。

偶発的な損傷を防ぐため、不一致が検出されるとアプリが警告します。ただし、選択したターゲットが正しいことを確認している場合（たとえば、デバイスを別のファームウェアバリアントに変換している場合や、以前の誤ったフラッシュを修正している場合など）、不一致ダイアログで**FORCE FLASH**をタップしてチェックを上書きし、フラッシュを進めることができます。
