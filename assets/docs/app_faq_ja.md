# ウォークスルー

## フェーズ 1: ファームウェアのキャッシュ
1. **インターネットに接続する:** スマートフォンがインターネット（例：自宅のWi-Fiまたはモバイルネットワーク）に接続されていることを確認してください。
2. **ファームウェアマネージャーを開く:** アプリのファームウェアマネージャーに移動します。
3. **リリースをダウンロードする:** 希望する ExpressLRS リリースの横にあるダウンロードアイコンをタップします。これにより、必要なファームウェアターゲットとハードウェア定義がスマートフォンに安全にキャッシュされ、100% オフラインで使用できるようになります。

## フェー�� 2: デバイスへの接続
1. **デバイスの電源を入れる:** ExpressLRS レシーバー (RX) またはトランスミッター (TX) の電源を入れます。
2. **ホットスポットを待つ:** デバイスが Wi-Fi ホットスポットモードに入るのを待ちます（高速点滅するLEDで示されます）。
3. **ホットスポットに接続する:** スマートフォンの Wi-Fi を、パスワード `expresslrs` を使用して `ExpressLRS RX` または `ExpressLRS TX` ネットワークに接続します。
* **注:** ELRS Mobile は強制ルーティングをネイティブで処理するため、スマートフォンが5G/LTEに無意識に切り替わることはありません。

## フェーズ 3: ファームウェアの書き込み
1. **デバイスの書き込みに移動:** メインダッシュボードから、**デバイスの書き込み**を選択します。
2. **ターゲットの選択:** カスケードドロップダウンを使用して、ベンダーと特定のハードウェアターゲットを選択します。
3. **バージョンの選択:** オフラインリポジトリから利用可能なファームウェアバージョンを選択します。
4. **設定とプロファイル:** カスタムの資格情報を読み込むために、**書き込みプロファイル**（例：「My Quads」、「Race Spec」）を選択または作成します。アプリケーションは、Wi-Fi SSID、Wi-Fi パスワード、Binding Phrase、Regulatory Domain、および Auto-On 間隔をこれらの名前付きプロファイルに保持するため、異なる設定を切り替える際に再入力する必要がありません。
5. **ビルドと書き込み:** **FLASH**をタップします。システムはバイナリにローカル資格情報をパッチし、アップロードします。
* **重要:** 成功確認が表示され、デバイスのLEDが点滅を再開するまで、必ず抜き差ししないでください！

# よくある質問

## ファームウェアを書き込むにはインターネット接続や携帯電話サービスが必要ですか？
いいえ。ELRS Mobile は**100% オフライン書き込み**に対応しています。以前にファームウェアマネージャーを介して自宅のWi-Fiでファームウェアバージョンをダウンロードしていれば、アプリは完全にオフラインでファームウェアを動的に組み立てて書き込むことができます。

## 書き込みプロファイルとは何ですか？また、どのように使用しますか？
書き込みプロファイルを使用すると、複数の書き込み設定（例：「My Quads」、「Stock / Factory Reset」、「Race Spec」）を保存および切り替えることができます。各プロファイルは、独自の Binding Phrase、Wi-Fi SSID、Wi-Fi パスワード、Regulatory Domain、および Wi-Fi Auto-On 間隔を安全に保存します。

使用方法：
1. **設定オプション**カードにある「書き込みプロファイル」ドロップダウンの横にある**+**（追加）アイコンをタップします。
2. 新しいプロファイルに名前を付け、設定をカスタマイズします。編集は即座に自動保存されます。
3. ドロップダウンから任意のプロファイルを選択すると、すべてのパラメーターが自動的に切り替わります。
4. プロファイルを削除するには、そのプロファイルを選択し、ゴミ箱/削除アイコンをタップします（削除するには少なくとも2つのプロファイルが必要です）。

## ESP8285 レシーバーを書き込む際に「容量不足」エラーが発生します。
ESP8285 チップ（多くの AIO ボードに見られるものなど）は、合計物理ストレージが1MBしかありません。Wi-Fi 経由でメジャーリリース（3.x から 4.x など）に直接アップデートすると、現在実行中のファームウェアの横で展開するには受信ファイルが大きすぎるため、デュアルパーティションスペースが不足する可能性があります。

**解決方法:** まず、レシーバーを中間バージョン（**3.6.3**など）に書き込みます。より軽量な 3.6.3 ファームウェアが実行されると、目的の 4.0 ターゲットに正常に書き込むのに十分なパーティションスペースが確保されます。または、設定で**エキスパートモード**を有効にし、ビルドされたバイナリをローカルに保存し、有線の Betaflight Passthrough 接続を介して手動で書き込みます。

## ラジオ用の ExpressLRS Lua スクリプトはどこにありますか？
ELRS Mobile には、ユニバーサルでバージョンに依存しない Lua スクリプトが組み込まれています！入手するには：
1. **設定**に移動し、**エキスパートモード**をオンにします。
2. **ELRS Lua スクリプトをエクスポート**をタップします。
3. これにより、`elrs.lua` がスマートフォンのローカルストレージに直接保存されます。ラジオの電源を入れ、USB経由でスマートフォンに接続し、ラジオで「USBストレージ」モードを選択して、スマートフォンのファイルマネージャーを使用してファイルを `SCRIPTS/TOOLS` フォルダーに転送してください。

**注:** 新しいスクリプトを使用する前に、ラジオのSDカードから以前のバージョンの elrs.lua スクリプト（例：elrs_v2.lua、elrs_v3.lua など）を削除する必要があります。

## ファームウェアファイルを書き込まずにスマートフォンに保存できますか？
はい。**設定**に移動して**エキスパートモード**を有効にすると、組み立てられたファームウェアバイナリを Over-The-Air (OTA) で即座に書き込む代わりに、モバイルデバイスのローカルストレージに直接保存する機能が解除されます。

これは、専用���ハードウェアプログラマー（STLink や FTDI アダプターなど）を使用してデバイスを手動で書き込みたい場合に特に便利です。

## 「ターゲット不一致」エラーが表示されます。どうすればよいですか？
ターゲット不一致エラーは、アプリで選択したハードウェアターゲットが、現在デバイスで実行されているファームウェアのターゲットと一致しない場合に発生します。

偶発的な損傷を防ぐため、不一致が検出された場合、アプリは警告を発します。ただし、選択したターゲットが正しいと確信している場合（たとえば、デバイスを別のファームウェアバリアントに変換している場合や、以前の間違った書き込みを修正している場合など）は、不一致ダイアログで**強制書き込み**をタップしてチェックを上書きし、書き込みを続行できます。
