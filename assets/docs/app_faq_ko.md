# 둘러보기

## 1단계: 펌웨어 캐싱
1. **인터넷 연결:** 휴대폰이 인터넷(예: 집 Wi-Fi 또는 모바일 네트워크)에 연결되어 있는지 확인하십시오.
2. **펌웨어 관리자 열기:** 앱에서 Firmware Manager로 이동하십시오.
3. **릴리스 다운로드:** 원하는 ExpressLRS 릴리스 옆에 있는 다운로드 아이콘을 누르십시오. 이렇게 하면 필요한 펌웨어 대상과 하드웨어 정의가 휴대폰에 안전하게 캐시되어 100% 오프라인에서 사용할 수 있습니다.

## 2단계: 장치 연결
1. **장치 전원 켜기:** ExpressLRS Receiver (RX) 또는 Transmitter (TX)의 전원을 켜십시오.
2. **핫스팟 대기:** 장치가 Wi-Fi Hotspot Mode에 진입할 때까지 기다리십시오(빠르게 깜빡이는 LED로 ���시됨).
3. **핫스팟 연결:** 암호 `expresslrs`를 사용하여 휴대폰의 Wi-Fi를 `ExpressLRS RX` 또는 `ExpressLRS TX` 네트워크에 연결하십시오.
* **참고:** ELRS Mobile은 강제 라우팅을 기본적으로 처리하여 휴대폰이 5G/LTE로 다시 조용히 전환되지 않도록 합니다.

## 3단계: 펌웨어 플래싱
1. **장치 플래싱으로 이동:** 메인 Dashboard에서 **Flash Device**를 선택하십시오.
2. **대상 선택:** 계단식 드롭다운을 사용하여 공급업체와 특정 하드웨어 대상을 선택하십시오.
3. **버전 선택:** 오프라인 저장소에서 사용 가능한 펌웨어 버전을 선택하십시오.
4. **구성:** 사용자 지정 자격 증명을 입력하십시오. 애플리케이션은 WiFi SSID, WiFi Password 및 Binding Phrase를 로컬 저장소에 유지하므로 다시 입력할 필요가 없습니다.
5. **빌드 및 플래싱:** **FLASH**를 누르십시오. 시스템은 로컬 자격 증명으로 바이너리를 패치하고 업로드합니다.
* **중요:** 항상 성공 확인을 기다리고, 장치 LED가 다시 깜빡이기 시작한 후에 플러그를 뽑으십시오!

# 자주 묻는 질문

## 펌웨어를 플래싱하려면 인터넷 연결이나 셀룰러 서비스가 필요합니까?
아니요. ELRS Mobile은 **100% 오프라인 ���래싱** 기능을 제공합니다. 이전에 집 Wi-Fi에 연결된 상태에서 Firmware Manager를 통해 펌웨어 버전을 다운로드했다면, 앱은 완전히 오프라인에서 펌웨어를 동적으로 조립하고 플래싱할 수 있습니다.

## ESP8285 수신기를 플래싱할 때 "공간 부족" 오류가 발생합니다.
ESP8285 chips (많은 AIO 보드에서 발견되는 것과 같은)은 총 1MB의 물리적 저장 공간만 가지고 있습니다. Wi-Fi를 통해 주요 릴리스(예: 3.x에서 4.x로)로 직접 업데이트하면, 들어오는 파일이 현재 실행 중인 펌웨어와 함께 압축을 해제하기에는 너무 크기 때문에 이중 파티션 공간이 부족해질 수 있습니다.

**해결 방법:** 먼저, 수신기를 중간 버전(예: **3.6.3**)으로 플래싱하십시오. 더 가벼운 3.6.3 펌웨어가 실행되면, 원하는 4.0 대상으로 성공적으로 플래싱할 수 있는 충분한 파티션 공간을 확보하게 됩니다. 또는 설정에서 **Expert Mode**를 활성화하고, 빌드된 바이너리를 로컬에 저장한 다음, 유선 Betaflight Passthrough 연결을 통해 수동으로 플래싱하십시오.

## 내 라디오용 ExpressLRS Lua 스크립트는 어디에서 찾을 수 있습니까?
ELRS Mobile에는 범용적이고 버전 독립적인 Lua 스크립트가 내��되어 있습니다! 스크립트를 얻으려면:
1. **Settings**으로 이동하여 **Expert Mode**를 켜십시오.
2. **Export ELRS Lua Script**를 누르십시오.
3. 이렇게 하면 `elrs.lua`가 휴대폰의 로컬 저장소에 직접 저장됩니다. 라디오를 켜고 USB를 통해 휴대폰에 연결한 다음, 라디오에서 "USB Storage" 모드를 선택했는지 확인하고 휴대폰의 파일 관리자를 사용하여 파일을 `SCRIPTS/TOOLS` 폴더로 전송하십시오.

**참고:** 새 스크립트를 사용하기 전에 라디오의 SD card에서 이전 버전의 elrs.lua 스크립트(예: elrs_v2.lua, elrs_v3.lua 등)를 삭제해야 합니다.

## 플래싱이 실패하여 장치가 응답하지 않으면 어떻게 해야 합니까?
플래싱 실패 후 장치가 응답하지 않으면 쉽게 복구할 수 있습니다:
1. 장치를 USB를 통해 연결하는 동안 BOOT 버튼을 길게 눌러 부트로더 모드로 진입하십시오.
2. 컴퓨터와 ELRS Web Flasher를 사용하여 유선 USB/UART 연결을 통해 장치를 다시 플래싱하십시오.

**참고:** Resources Tab에 이 작업을 수행하는 방법을 보여주는 비디오 링크가 있습니다.

## 펌웨어 파일을 플래싱하지 않고 휴대폰에 저장할 수 있��니까?
예. **Settings**으로 이동하여 **Expert Mode**를 활성화하면, 조립된 펌웨어 바이너리를 Over-The-Air (OTA)로 즉시 플래싱하는 대신 모바일 장치의 로컬 저장소에 직접 저장할 수 있는 기능이 잠금 해제됩니다.

이는 전용 하드웨어 프로그래머(예: STLink 또는 FTDI adapter)를 사용하여 장치를 수동으로 플래싱하려는 경우 특히 유용합니다.

## "대상 불일치" 오류가 발생합니다. 어떻게 해야 합니까?
대상 불일치 오류는 앱에서 선택한 하드웨어 대상이 현재 장치에서 실행 중인 펌웨어의 대상과 일치하지 않을 때 발생합니다.

현재 앱은 장치에서 현재 실행 중인 대상과 다른 대상을 플래싱하는 것을 지원하지 않습니다.
