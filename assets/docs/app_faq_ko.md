# 따라하기

## 1단계: 펌웨어 캐싱
1. **인터넷 연결:** 휴대폰이 인터넷(예: 집 Wi-Fi 또는 모바일 네트워크)에 연결되어 있는지 확인하십시오.
2. **펌웨어 관리자 열기:** 앱에서 펌웨어 관리자로 이동하십시오.
3. **릴리스 다운로드:** 원하는 ExpressLRS 릴리스 옆에 있는 다운로드 아이콘을 탭하십시오. 이렇게 하면 필요한 펌웨어 타겟과 하드웨어 정의가 휴대폰에 안전하게 캐시되어 100% 오프라인에서 사용할 수 있습니다.

## 2단계: 장치 연결
1. **장치 전원 켜기:** ExpressLRS 수신기(RX) 또는 송신기(TX)의 전원을 켜십시오.
2. **핫스팟 대기:** 장치가 Wi-Fi Hotspot Mode에 진입할 때까지 기다리십시오 (빠르게 깜박이는 LED로 표시됨).
3. **핫스팟 연결:** 휴대폰의 Wi-Fi를 `ExpressLRS RX` 또는 `ExpressLRS TX` 네트워크에 `expresslrs` 암호를 사용하여 연결하십시오.
* **참고:** ELRS Mobile은 강제 라우팅을 기본적으로 처리하여 휴대폰이 5G/LTE로 자동으로 전환되지 않도록 합니다.

## 3단계: 펌웨어 플래싱
1. **장치 플래시로 이동:** 메인 대시보드에서 **Flash Device**를 선택하십시오.
2. **타겟 선택:** 계단식 드롭다운을 사용하여 공급업체와 특정 하드웨어 타겟을 선택하십시오.
3. **버전 선택:** 오프라인 저장소에서 사용 가능한 펌웨어 버전을 선택하십시오.
4. **구성 및 프로필:** **Flashing Profile** (예: "My Quads", "Race Spec")을 선택하거나 생성하여 사용자 정의 자격 증명을 로드하십시오. 이 애플리케이션은 Wi-Fi SSID, Wi-Fi Password, Binding Phrase, Regulatory Domain 및 Auto-On 간격을 이러한 이름 지정된 프로필에 유지하여 다른 설정 간에 전환할 때 다시 입력할 필요가 없도록 합니다.
5. **빌드 및 플래시:** **FLASH**를 탭하십시오. 시스템이 바이너리에 로컬 자격 증명을 패치하고 업로드합니다.
* **중요:** 항상 성공 확인 메시지를 기다리고, 장치 LED가 다시 깜박이기 시작한 후에 전원을 뽑으십시오!

# 자주 묻는 질문 (FAQ)

## 펌웨어를 플래싱하려면 인터넷 연결 또는 셀룰러 서비스가 필요합니까?
아니요. ELRS Mobile은 **100% 오프라인 플래싱** 기능을 제공합니다. 집 Wi-Fi에 연결되어 있을 때 펌웨어 관리자를 통해 펌웨어 버전을 미리 다운로드했다면, 앱은 펌웨어를 완전히 오프라인으로 동적으로 조립하고 플래싱할 수 있습니다.

## Flashing Profile이란 무엇이며 어떻게 사용합니까?
Flashing Profile을 사용하면 여러 플래싱 구성 (예: "My Quads", "Stock / Factory Reset", "Race Spec")을 저장하고 전환할 수 있습니다. 각 프로필은 자체 Binding Phrase, Wi-Fi SSID, Wi-Fi password, Regulatory Domain 및 Wi-Fi Auto-On interval을 안전하게 저장합니다.

사용 방법:
1. **Configuration Options** 카드에서 "Flashing Profile" 드롭다운 옆에 있는 **+** (추가) 아이콘을 탭하십시오.
2. 새 프로필의 이름을 지정하고 설정을 사용자 정의하십시오. 편집 내용은 즉시 자동 저장됩니다.
3. 드롭다운에서 프로필을 선택하여 모든 매개변수를 자동으로 교체하십시오.
4. 프로필을 삭제하려면 해당 프로필을 선택하고 휴지통/삭제 아이콘을 탭하십시오 (삭제하려면 최소 두 개의 프로필이 있어야 합니다).

## ESP8285 수신기를 플래싱할 때 "Not enough space" 오류가 발생합니다.
ESP8285 칩 (많은 AIO 보드에서 발견되는 것과 같은)은 총 1MB의 물리적 저장 공간만 가지고 있습니다. Wi-Fi를 통해 주요 릴리스 (예: 3.x에서 4.x로)로 직접 업데이트하면, 들어오는 파일이 현재 실행 중인 펌웨어와 함께 압축을 풀기에 너무 커서 이중 파티션 공간이 부족할 수 있습니다.

**해결 방법:** 먼저 수신기를 중간 버전 (예: **3.6.3**)으로 플래싱하십시오. 더 가벼운 3.6.3 펌웨어가 실행되면, 원하는 4.0 타겟으로 성공적으로 플래싱할 수 있는 충분한 파티션 공간이 확보될 것입니다. 또는 설정에서 **Expert Mode**를 활성화하고, 빌드된 바이너리를 로컬에 저장한 다음, 유선 Betaflight Passthrough 연결을 통해 수동으로 플래싱하십시오.

## 제 조종기를 위한 ExpressLRS Lua 스크립트는 어디에서 찾을 수 있습니까?
ELRS Mobile에는 범용의, 버전 독립적인 Lua 스크립트가 내장되어 있습니다! 얻는 방법:
1. **Settings**로 이동하여 **Expert Mode**를 켜십시오.
2. **Export ELRS Lua Script**를 탭하십시오.
3. 이렇게 하면 `elrs.lua`가 휴대폰의 로컬 저장소에 직접 저장됩니다. 조종기의 전원을 켜고 USB를 통해 휴대폰에 연결한 다음, 조종기에서 "USB Storage" 모드를 선택하고 휴대폰의 파일 관리자를 사용하여 파일을 `SCRIPTS/TOOLS` 폴더로 전송하십시오.

**참고:** 새 스크립트를 사용하기 전에 조종기 SD 카드에서 이전 버전의 elrs.lua 스크립트 (예: elrs_v2.lua, elrs_v3.lua 등)를 삭제해야 합니다.

## 플래싱이 실패하여 장치가 응답하지 않으면 어떻게 해야 합니까?
플래싱 실패 후 장치가 응답하지 않으면 쉽게 복구할 수 있습니다:
1. 장치의 BOOT 버튼을 누른 상태로 USB를 통해 연결하여 부트로더 모드로 진입하십시오.
2. 컴퓨터와 ELRS Web Flasher를 사용하여 유선 USB/UART 연결을 통해 장치를 다시 플래싱하십시오.
3. Wi-Fi 기능이 있는 장치의 경우 BOOT 버튼을 누른 상태로

**참고:** 리소스 탭에 이를 수행하는 방법을 보여주는 비디오 링크가 있습니다.

## 펌웨어 파일을 플래싱하지 않고 휴대폰에 저장할 수 있습니까?
예. **Settings**로 이동하여 **Expert Mode**를 활성화하면, 조립된 펌웨어 바이너리를 즉시 OTA (Over-The-Air) 플래싱하는 대신 모바일 장치의 로컬 저장소에 직접 저장할 수 있는 기능이 잠금 해제됩니다.

이는 전용 하드웨어 프로그래머 (예: STLink 또는 FTDI 어댑터)를 사용하여 장치를 수동으로 플래싱하려는 경우 특히 유용합니다.

## "Target Mismatch" 오류가 발생합니다. 어떻게 해야 합니까?
타겟 불일치 오류는 앱에서 선택한 하드웨어 타겟이 장치에서 현재 실행 중인 펌웨어의 타겟과 일치하지 않을 때 발생합니다.

우발적인 손상을 방지하기 위해 불일치가 감지되면 앱에서 경고합니다. 하지만 선택한 타겟이 올바르다고 확신한다면 (예: 장치를 다른 펌웨어 변형으로 전환하거나 이전의 잘못된 플래싱을 수정하는 경우), 불일치 대화 상자에서 **FORCE FLASH**를 탭하여 확인을 무시하고 플래싱을 진행할 수 있습니다.
