# ขั้นตอนการใช้งาน

## ขั้นตอนที่ 1: การแคชเฟิร์มแวร์
1. **เชื่อมต่ออินเทอร์เน็ต:** ตรวจสอบให้แน่ใจว่าโทรศัพท์ของคุณเชื่อมต่ออินเทอร์เน็ต (เช่น Wi-Fi ที่บ้านหรือเครือข่ายมือถือ)
2. **เปิด Firmware Manager:** ไปที่ Firmware Manager ในแอป
3. **ดาวน์โหลด Release:** แตะไอคอนดาวน์โหลดถัดจาก ExpressLRS release ที่คุณต้องการ สิ่งนี้จะแคชเป้าหมายเฟิร์มแ��ร์และคำจำกัดความฮาร์ดแวร์ที่จำเป็นอย่างปลอดภัยบนโทรศัพท์ของคุณสำหรับการใช้งานแบบออฟไลน์ 100%

## ขั้นตอนที่ 2: การเชื่อมต่อกับอุปกรณ์ของคุณ
1. **เปิดอุปกรณ์:** เปิด ExpressLRS Receiver (RX) หรือ Transmitter (TX) ของคุณ
2. **รอ Hotspot:** รอให้อุปกรณ์เข้าสู่โหมด Wi-Fi Hotspot (ระบุด้วยไฟ LED กระพริบอย่างรวดเร็ว)
3. **เชื่อมต่อกับ Hotspot:** เชื่อมต่อ Wi-Fi ของโทรศัพท์ของคุณเข้ากับเครือข่าย `ExpressLRS RX` หรือ `ExpressLRS TX` โดยใช้รหัสผ่าน `expresslrs`
* **หมายเหตุ:** ELRS Mobile จัดการการกำหนดเส้นทางแบบบังคับโดยกำเนิด เพื่อให้แน่ใจว่าโทรศัพท์ของคุณจะไม่สลับกลับไปใช้ 5G/LTE โดยอัตโนมัติ

## ข��้นตอนที่ 3: การแฟลชเฟิร์มแวร์
1. **ไปที่ Flash Device:** จากหน้า Dashboard หลัก ให้เลือก **Flash Device**
2. **การเลือกเป้าหมาย:** ใช้เมนูแบบเลื่อนลงที่ต่อเนื่องกันเพื่อเลือกผู้ผลิตและเป้าหมายฮาร์ดแวร์ที่เฉพาะเจาะจง
3. **การเลือกเวอร์ชัน:** เลือกเวอร์ชันเฟิร์มแวร์ที่มีอยู่ในคลังข้อมูลออฟไลน์ของคุณ
4. **การตั้งค่า:** ป้อนข้อมูลประจำตัวที่คุณกำหนดเอง แอปจะคงค่า WiFi SSID, WiFi Password และ Binding Phrase ไว้ในที่เก็บข้อมูลภายในเครื่อง ดังนั้นคุณไม่จำเป็นต้องป้อนซ้ำ
5. **สร้างและแฟลช:** แตะ **FLASH** ระบบจะแก้ไขไบนารีด้วยข้อมูลประจำตัวในเครื่องของคุณและอัปโหลด
* **สำคัญ:** โปรดรอการยืนยันความสำเร็จและให้ไฟ LED ของอุปกรณ์กลับมากระพริบอีกครั้งก่อนถอดปลั๊ก!

# คำถามที่พบบ่อย

## ฉันจำเป็นต้องเชื่อมต่ออินเทอร์เน็ตหรือบริการเซลลูลาร์เพื่อแฟลชเฟิร์มแวร์หรือไม่?
ไม่ ELRS Mobile มีคุณสมบัติ **การแฟลชแบบออฟไลน์ 100%** ตราบใดที่คุณได้ดาวน์โหลดเวอร์ชันเฟิร์มแวร์ผ่าน Firmware Manager ขณะเชื่อมต่อ Wi-Fi ที่บ้านแล้ว แอปจะสามารถประกอบและแฟลชเฟิร์มแวร์ได้อย่างสมบูรณ์แบบออฟไลน์

## ฉันได้รับข้อผิดพลาด "Not enough space" (พื้นที่ไม่เพียงพอ) เมื่อแฟลช ESP8285 receiver ของฉัน
ชิป ESP8285 (เช่นที่พบในบอร์ด AIO หลายตัว) มีพื้นที่เก็บข้อมูลทางกายภาพรวมเพียง 1MB เท่านั้น การอัปเดตโดยตรงไปยังรุ่นหลัก (เช่นจาก 3.x เป็น 4.x) ผ่าน Wi-Fi อาจทำให้พื้นที่พาร์ติชันคู่ไม่เพียงพอ เนื่องจากไฟล์ที่เข้ามามีขนาดใหญ่เกินไปที่จะคลายแพ็คพร้อมกับเฟิร์มแวร์ที่กำลังทำงานอยู่

**วิธีแก้ไข:** ขั้นแรก ให้แฟลช receiver ของคุณไปยังเวอร์ชันกลาง (เช่น **3.6.3**) เมื่อมันรันเฟิร์มแวร์ 3.6.3 ที่มีขนาดเล็กกว่า คุณจะมีพื้นที่พาร์ติชันเพียงพอที่จะแฟลชไปยังเป้าหมาย 4.0 ที่คุณต้องการได้สำเร็จ อีกทางหนึ่ง ให้เปิดใช้งาน **Expert Mode** ใน Settings บันทึกไบนารีที่สร้���งขึ้นในเครื่อง และแฟลชด้วยตนเองผ่านการเชื่อมต่อ Betaflight Passthrough แบบมีสาย

## ฉันจะหา ExpressLRS Lua script สำหรับวิทยุของฉันได้ที่ไหน?
ELRS Mobile มาพร้อมกับ Lua script สากลที่ไม่ขึ้นกับเวอร์ชันที่สร้างมาในตัว! วิธีรับ:
1. ไปที่ **Settings** และสลับเปิด **Expert Mode**
2. แตะ **Export ELRS Lua Script**
3. สิ่งนี้จะบันทึก `elrs.lua` ไปยังที่เก็บข้อมูลภายในของโทรศัพท์ของคุณโดยตรง เปิดวิทยุของคุณและเสียบเข้ากับโทรศัพท์ของคุณผ่าน USB ตรวจสอบให้แน่ใจว่าได้เลือกโหมด "USB Storage" บนวิทยุของคุณ และถ่ายโอนไฟล์ไปยังโฟลเดอร์ `SCRIPTS/TOOLS` ของคุณโดยใช้ตัวจัดการไฟล์ในโทรศัพท์ของคุณ

**หมา��เหตุ:** คุณต้องลบ Lua script เวอร์ชันก่อนหน้าทั้งหมด (เช่น elrs_v2.lua, elrs_v3.lua, เป็นต้น) ออกจาก SD card ของวิทยุของคุณก่อนใช้ script ใหม่นี้

## จะเกิดอะไรขึ้นหากการแฟลชล้มเหลวและอุปกรณ์ของฉันไม่ตอบสนอง?
หากอุปกรณ์ของคุณไม่ตอบสนองหลังจากการแฟลชล้มเหลว คุณสามารถกู้คืนได้อย่างง่ายดาย:
1. กดปุ่ม BOOT บนอุปกรณ์ค้างไว้ขณะเสียบสาย USB เพื่อเข้าสู่โหมด bootloader
2. ใช้คอมพิวเตอร์และ ELRS Web Flasher เพื่อแฟลชอุปกรณ์ใหม่ผ่านการเชื่อมต่อ USB/UART แบบมีสาย
3. สำหรับอุปกรณ์ที่รองรับ Wi-Fi คุณสามารถกด BOOT ค้างไว้

**หมายเหตุ:** มีลิงก์วิดีโอในแท็บ Resources ที่แสดงว��ธีทำสิ่งนี้

## ฉันสามารถบันทึกไฟล์เฟิร์มแวร์ลงในโทรศัพท์โดยไม่ต้องแฟลชได้หรือไม่?
ได้ โดยไปที่ **Settings** และเปิดใช้งาน **Expert Mode** คุณจะปลดล็อกความสามารถในการบันทึกไบนารีเฟิร์มแวร์ที่ประกอบเสร็จแล้วโดยตรงไปยังที่เก็บข้อมูลภายในเครื่องของอุปกรณ์มือถือของคุณ แทนที่จะแฟลชทันทีแบบ Over-The-Air (OTA)

วิธีนี้มีประโยชน์อย่างยิ่งหากคุณต้องการแฟลชอุปกรณ์ด้วยตนเองโดยใช้โปรแกรมเมอร์ฮาร์ดแวร์เฉพาะ (เช่น STLink หรือ FTDI adapter)

## ฉันได้รับข้อผิดพลาด "Target Mismatch" ฉันควรทำอย่างไร?
ข้อผิดพลาด "Target Mismatch" เกิดขึ้นเมื่อเป้าหมายฮา��์ดแวร์ที่คุณเลือกในแอปไม่ตรงกับเป้าหมายของเฟิร์มแวร์ที่กำลังทำงานอยู่บนอุปกรณ์

ปัจจุบันแอปไม่รองรับการแฟลชเป้าหมายที่แตกต่างจากที่กำลังทำงานอยู่บนอุปกรณ์
