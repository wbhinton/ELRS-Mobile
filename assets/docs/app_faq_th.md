# ขั้นตอนการใช้งาน

## ขั้นตอนที่ 1: การแคชเฟิร์มแวร์
1. **เชื่อมต่ออินเทอร์เน็ต:** ตรวจสอบให้แน่ใจว่าโทรศัพท์ของคุณเชื่อมต่อกับอินเทอร์เน็ตอยู่ (เช่น Wi-Fi ที่บ้านหรือเครือข่ายมือถือ)
2. **เปิด Firmware Manager:** ไปที่ Firmware Manager ในแอป
3. **ดาวน์โหลด Release:** แตะไอคอนดาวน์โหลดถัดจาก ExpressLRS release ที่คุณต้องการ ซึ่งจะแคชเป้าหมายเฟิร์มแวร์และคำจำกัดความฮาร์ดแวร์ที่จำเป็นอย่างปลอดภัยบนโทรศัพท์ของคุณสำหรับการใช้งานแบบออฟไลน์ 100%

## ขั้นตอนที่ 2: การเชื่อมต่อกับอุปกรณ์ของคุณ
1. **เปิดอุปกรณ์:** เปิด ExpressLRS Receiver (RX) หรือ Transmitter (TX) ของคุณ
2. **รอ Hotspot:** รอให้อุปกรณ์เข้าสู่ Wi-Fi Hotspot Mode (สังเกตได้จาก LED ที่กะพริบเร็ว)
3. **เชื่อมต่อกับ Hotspot:** เชื่อมต่อ Wi-Fi ของโทรศัพท์ของคุณเข้ากับเครือข่าย `ExpressLRS RX` หรือ `ExpressLRS TX` โดยใช้รหัสผ่าน `expresslrs`
* **หมายเหตุ:** ELRS Mobile จัดการการกำหนดเส้นทางแบบบังคับโดยกำเนิด ทำให้มั่นใจว่าโทรศัพท์ของคุณจะไม่เปลี่ยนกลับไปใช้ 5G/LTE โดยไม่รู้ตัว

## ขั้นตอนที่ 3: การแฟลชเฟิร์มแวร์
1. **ไปที่ Flash Device:** จากหน้า Dashboard หลัก ให้เลือก **Flash Device**
2. **การเลือก Target:** ใช้ดรอปดาวน์แบบเรียงซ้อนเพื่อเลือกผู้จำหน่ายและฮาร์ดแวร์ target เฉพาะ
3. **การเลือกเวอร์ชัน:** เลือกเวอร์ชันเฟิร์มแวร์ที่มีอยู่จาก repository ออฟไลน์ของคุณ
4. **การกำหนดค่าและโปรไฟล์:** เลือกหรือสร้าง **Flashing Profile** (เช่น "My Quads", "Race Spec") เพื่อโหลดข้อมูลประจำตัวที่กำหนดเองของคุณ แอปพลิเคชันจะเก็บ Wi-Fi SSID, Wi-Fi Password, Binding Phrase, Regulatory Domain และ Auto-On intervals ไว้ในโปรไฟล์ที่มีชื่อเหล่านี้ เพื่อที่คุณจะได้ไม่ต้องป้อนข้อมูลเหล่านั้นซ้ำเมื่อสลับระหว่างการตั้งค่าต่างๆ
5. **Build & Flash:** แตะ **FLASH** ระบบจะแพตช์ไบนารีด้วยข้อมูลประจำตัวในเครื่องของคุณและอัปโหลด
* **สำคัญ:** ควรอุปกรณ์จนกว่าจะได้รับการยืนยันความสำเร็จและ LED ของอุปกรณ์กลับมากะพริบอีกครั้งก่อนที่จะถอดปลั๊ก!

# คำถามที่พบบ่อย

## ฉันจำเป็นต้องมีการเชื่อมต่ออินเทอร์เน็ตหรือบริการเซลลูลาร์เพื่อแฟลชเฟิร์มแวร์หรือไม่?
ไม่ ELRS Mobile มีคุณสมบัติ **การแฟลชแบบออฟไลน์ 100%** ตราบใดที่คุณได้ดาวน์โหลดเวอร์ชันเฟิร์มแวร์ผ่าน Firmware Manager ขณะเชื่อมต่อ Wi-Fi ที่บ้าน แอปก็สามารถประกอบและแฟลชเฟิร์มแวร์แบบออฟไลน์ได้อย่างสมบูรณ์

## Flashing Profiles คืออะไร และฉันจะใช้งานได้อย่างไร?
Flashing Profiles ช่วยให้คุณสามารถบันทึกและสลับระหว่างการกำหนดค่าการแฟลชหลายแบบได้ (เช่น "My Quads", "Stock / Factory Reset", "Race Spec") แต่ละโปรไฟล์จะจัดเก็บ binding phrase, Wi-Fi SSID, Wi-Fi password, regulatory domains และ Wi-Fi auto-on interval ของตัวเองไว้อย่างปลอดภัย

หากต้องการใช้งาน:
1. แตะไอคอน **+** (เพิ่ม) ถัดจากดรอปดาวน์ "Flashing Profile" ในการ์ด **Configuration Options**
2. ตั้งชื่อโปรไฟล์ใหม่ของคุณและปรับแต่งการตั้งค่า การแก้ไขจะถูกบันทึกอัตโนมัติทันที
3. เลือกโปรไฟล์ใดก็ได้จากดรอปดาวน์เพื่อสลับพารามิเตอร์ทั้งหมดโดยอัตโนมัติ
4. หากต้องการลบโปรไฟล์ ให้เลือกโปรไฟล์นั้นแล้วแตะไอคอนถังขยะ/ลบ (ต้องมีโปรไฟล์อย่างน้อยสองโปรไฟล์จึงจะสามารถลบได้)

## ฉันได้รับข้อผิดพลาด "Not enough space" เมื่อแฟลชตัวรับ ESP8285 ของฉัน
ชิป ESP8285 (เช่นที่พบในบอร์ด AIO หลายรุ่น) มีพื้นที่เก็บข้อมูลจริงรวมเพียง 1MB การอัปเดตโดยตรงไปยัง release หลัก (เช่นจาก 3.x เป็น 4.x) ผ่าน Wi-Fi อาจทำให้พื้นที่ dual-partition ไม่เพียงพอเนื่องจากไฟล์ที่เข้ามามีขนาดใหญ่เกินไปที่จะคลายแพ็คร่วมกับเฟิร์มแวร์ที่กำลังทำงานอยู่

**วิธีแก้ไข:** ขั้นแรก ให้แฟลชตัวรับของคุณไปยังเวอร์ชันระดับกลาง (เช่น **3.6.3**) เมื่อเฟิร์มแวร์ 3.6.3 ที่มีขนาดเล็กกว่าทำงานอยู่ คุณจะมีพื้นที่ partition เพียงพอที่จะแฟลชไปยัง target 4.0 ที่คุณต้องการได้อย่างสำเร็จ อีกทางหนึ่ง ให้เปิดใช้งาน **Expert Mode** ใน Settings บันทึกไบนารีที่สร้างขึ้นในเครื่อง และแฟลชด้วยตนเองผ่านการเชื่อมต่อ Betaflight Passthrough แบบมีสาย

## ฉันจะหา ExpressLRS Lua script สำหรับวิทยุของฉันได้ที่ไหน?
ELRS Mobile มาพร้อมกับ Lua script สากลที่ไม่ขึ้นกับเวอร์ชันที่สร้างขึ้นมาในตัว! หากต้องการ:
1. ไปที่ **Settings** และเปิดใช้งาน **Expert Mode**
2. แตะ **Export ELRS Lua Script**
3. ซึ่งจะบันทึก `elrs.lua` ลงในที่เก็บข้อมูลภายในของโทรศัพท์ของคุณโดยตรง เปิดวิทยุของคุณแล้วเสียบเข้ากับโทรศัพท์ผ่าน USB ตรวจสอบให้แน่ใจว่าได้เลือกโหมด "USB Storage" บนวิทยุของคุณและถ่ายโอนไฟล์ไปยังโฟลเดอร์ `SCRIPTS/TOOLS` โดยใช้ตัวจัดการไฟล์ในโทรศัพท์ของคุณ

**หมายเหตุ:** คุณต้องลบ Lua script เวอร์ชั่นก่อนหน้าของ elrs.lua (เช่น elrs_v2.lua, elrs_v3.lua เป็นต้น) ออกจากการ์ด SD ของวิทยุของคุณก่อนที่จะใช้ script ใหม่

## จะเกิดอะไรขึ้นหากการแฟลชล้มเหลวและอุปกรณ์ของฉันไม่ตอบสนอง?
หากอุปกรณ์ของคุณไม่ตอบสนองหลังจากการแฟลชล้มเหลว คุณสามารถกู้คืนได้อย่างง่ายดาย:
1. กดปุ่ม BOOT บนอุปกรณ์ค้างไว้ขณะเสียบเข้ากับ USB เพื่อเข้าสู่โหมด bootloader
2. ใช้คอมพิวเตอร์และ ELRS Web Flasher เพื่อแฟลชอุปกรณ์ใหม่ผ่านการเชื่อมต่อ USB/UART แบบมีสาย
3. สำหรับอุปกรณ์ที่รองรับ Wi-Fi คุณสามารถกด BOOT ค้างไว้

**หมายเหตุ:** มีลิงก์วิดีโอในแท็บ Resources ที่แสดงวิธีการทำเช่นนี้

## ฉันสามารถบันทึกไฟล์เฟิร์มแวร์ลงในโทรศัพท์โดยไม่ต้องแฟลชได้หรือไม่?
ใช่ ด้วยการไปที่ **Settings** และเปิดใช้งาน **Expert Mode** คุณจะสามารถบันทึก binary ของเฟิร์มแวร์ที่ประกอบเสร็จแล้วลงในที่เก็บข้อมูลภายในของอุปกรณ์มือถือของคุณได้โดยตรง แทนที่จะแฟลช Over-The-Air (OTA) ทันที

สิ่งนี้มีประโยชน์อย่างยิ่งหากคุณต้องการแฟลชอุปกรณ์ด้วยตนเองโดยใช้ hardware programmer เฉพาะ (เช่น STLink หรือ FTDI adapter)

## ฉันได้รับข้อผิดพลาด "Target Mismatch" ฉันควรทำอย่างไร?
ข้อผิดพลาด target mismatch เกิดขึ้นเมื่อฮาร์ดแวร์ target ที่คุณเลือกในแอปไม่ตรงกับ target ของเฟิร์มแวร์ที่กำลังทำงานอยู่บนอุปกรณ์

เพื่อป้องกันความเสียหายโดยไม่ตั้งใจ แอปจะเตือนคุณหากตรวจพบความไม่ตรงกัน อย่างไรก็ตาม หากคุณแน่ใจว่า target ที่เลือกถูกต้อง (เช่น หากคุณกำลังแปลงอุปกรณ์เป็นเฟิร์มแวร์เวอร์ชันอื่น หรือแก้ไขการแฟลชที่ผิดพลาดก่อนหน้านี้) คุณสามารถแตะ **FORCE FLASH** ในกล่องโต้ตอบ mismatch เพื่อข้ามการตรวจสอบและดำเนินการแฟลชต่อได้
