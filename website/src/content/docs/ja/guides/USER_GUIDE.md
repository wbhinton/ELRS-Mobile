ELRS Mobileは、外出先でノートパソコンやインターネット接続がなくても、Wi-Fi経由でスマートフォンからExpressLRSレシーバー（RX）とトランスミッター（TX）をフラッシュおよび設定できます。ESPベースのハードウェア（ESP8285、ESP32、ESP32-C3、ESP32-S3）およびExpressLRS 3.3.xおよび4.xファームウェアに対応しています。対応するすべてのデバイスについては、[サポートされているハードウェア](/supported_hardware)をご覧ください。

ワークフローは2つの段階に分かれます。インターネットがある場所でファームウェアをダウンロードし、その後はどこでもフラッシュできます。

## クイックスタート: 最初のデバイスをフラッシュする

### ステップ1: ファームウェアのダウンロード (自宅で)

1.  Dashboardで**Firmware Manager**を開きます。
2.  目的のExpressLRSバージョンの横にあるダウンロードアイコンをタップします。バージョン3.3.0以降のみがリストされます。これらはELRS Mobileが構築されている統一ファームウェアを最初に搭載したものです。
3.  ダウンロードが完了すると、バージョンは**Ready for offline use**と表示されます。ファームウェアとそれに必要なハードウェア定義がスマートフォンに保存されます。

ファームウェアはご自宅のWi-Fiまたはモバイルデータでダウンロードしてください。スマートフォンがレシーバーまたはトランスミッターのWi-Fiホットスポットに接続されている間は、そのネットワークにはインターネットがないためダウンロードできません。

ヘッダーには、制限に対して保存されているバージョンの数が表示されます。**Settings → App & Storage → Max Cached Versions**���制限を変更し、不要になったバージョンを削除できます。

### ステップ2: デバイスに接続する

1.  レシーバーまたはトランスミッターの電源を入れ、Wi-Fiホットスポットが起動するのを待ちます。デフォルトでは、パートナーに接続していない場合、電源投入から60秒後に起動します。トランスミッターは、ラジオのExpressLRS LuaスクリプトからWi-Fiを開始することもできます。
2.  スマートフォンで、**ExpressLRS RX**または**ExpressLRS TX**ネットワークに接続します。パスワードは`expresslrs`です。
3.  ELRS Mobileを開きます。Dashboardがデバイスを自動的に検出し、製品名、ファームウェアバージョン、ターゲット、規制ドメインを表示します。

Dashboardに**No Device Found**と表示された場合は、**Retry**をタップしてください。デバイスが別のネットワーク（例えば、自宅のWi-Fiに接続している場合）にある場合は、デバイスカードのギアアイコンをタップし、そのIPアドレスを入力してください。

ファームウェアが3.1より古いデバイスも検出されるため、最新のリリースに更新できます。

### ステップ3: フラッシュ

1.  Dashboardで**Flash Device**をタップします。
2.  ターゲットを確認します。アプリは可能な場合、接続されているデバイスに一致するターゲットを事前に選択します。そうでない場合は、Device Type、Device Vendor、Regulatory & Frequency、Device Targetを選択します。
3.  ファームウェアバージョンを選択します。ダウンロード済みのバージョンは**(Cached)**と表示されます。ハードウェアが現在持っているバージョンよりも新しいバージョンを必要とする場合、アプリはその旨を伝え、互換性のあるバージョンをダウンロードするよう提案します。
4.  ファームウェアオプション（フラッシングプロファイル、バインディングフレーズ、Wi-Fiネットワークとパスワード、規制ドメイン、Wi-Fi自動オン間隔）を確認します。
5.  **Flash**をタップします。

プログレスバーは各ステップ（ダウンロードしたファームウェアの特定と解凍、設定によるビルド、アップロード、デバイスがインストールして再起動する間の**Writing to Device — Please Wait**）を追跡します。デバイスが確認すると、**Flashing Successful! Device is rebooting**と表示され、デバイスが再起動する��Dashboardが再接続されます。

## 安全確認

アプリはフラッシュ前に選択内容をチェックし、問題があるように見える場合は停止します。

:::danger[互換性のないチップ]
あるチップ用のファームウェアは、別のチップでは決して動作しません（例：ESP8285レシーバーでESP32ファームウェア）。アプリはフラッシュをブロックし、それぞれのチップが何であるかを伝えます。デバイスのチップに合ったターゲットを選択してください。
:::

:::caution[ターゲットの不一致]
選択したターゲットがデバイスが報告する製品と一致しない場合、**Target Mismatch**と表示されます。まず選択内容を確認してください。それが正しいと確信できる場合（例えば、不良なフラッシュからの回復や新しいターゲット定義への移行など）、**Force Flash**をタップしてください。
:::

:::note[バインディングフレーズなし]
バインディングフレーズなしでフラッシュすることも可能ですが、デバイスはデフォルト（空）のフレーズを使用してのみバインドされます。続行する前にアプリが確認します。
:::

:::caution[フラッシュ未確認]
フラッシュを確認する前にデバイスが切断された場合（電源が失われた、再起動した、またはWi-Fi接続が切れたなど）、アプリはアップデートが完了したかどうかを判断できません。成功を報告する代わりに、アンバー色の警告を表示します。再接続してDashboardでファームウェアバージョンを確認し、変更されていない場合は再度フラッシュしてください。
:::

## フラッシングプロファイル

フラッシングプロファイルは、バインディングフレーズ、自宅のWi-Fiネットワークとパスワード、デフォルトの規制ドメイン、Wi-Fi自動オン間隔を名前の下に保存します。フリートまたはラジオのセットアップごとに1つを使用し、ワンタップで切り替えることができます。

プロファイルは**Settings → Profiles & Network**で管理します。

-   **追加:** **+**をタップし、名前を入力して**Add**をタップします。
-   **切り替え:** **Flashing Profile**リストからプロファイルを選択します。フラッシング画面でも利用可能です。
-   **編集:** 任意のフィールドを変更します。アクティブなプロファイルは自動的に保存されます。
-   **削除:** プロファイルを選択し、削除アイコンをタップします。常に少なくとも1つのプロファイルが保持されます。

バインディングフレーズとWi-Fiパスワードは、スマートフォンの暗号化された安全なストレージに保存されます。

## デバイス設定

Dashboardで**Device Config**をタップすると、接続されているデバイスのExpressLRS設定ページがアプリ内で開きます。これを使用して、Wi-Fiとバインディング設定、モデルマッチ、シリアルプロトコル、PWM出力マッピング、その他のデバイスオプションを変更できます。アプリはこのページをデバイスにロックします。

---

## 設定

| セクション | 内容 |
| :--- | :--- |
| Profiles & Network | フラッシングプロファイル、バインディングフレーズ、自宅のWi-Fiネットワークとパスワード、デフォルトの2.4 GHzおよびsub-GHz規制ドメイン |
| App & Storage | 最大キャッシュバージョン、Firmware Manager、ファームウェアキャッシュのクリア、アプリ言語、匿名使用状況分析（デフォルトでオン。**Share Analytics**でオフにできます） |
| Advanced & Debug | エキスパートモードとそのツール（下記参照） |
| About & Legal | アプリバージョン、法的通知とライセンス、開発のサポート、および直ダウンロード版APKでの**Check for Updates** |

アプリの言語は、Settingsまたは上部バーの言語ボタンから変更できます。ELRS Mobileは18言語で利用可能です。

## エキスパートモード

**Settings → Advanced & Debug → Expert Mode**をオンにすると、以下の機能が利用可能になります。

-   **STM32ターゲット。**古いSTM32ベースのハードウェアはWi-Fi経由でフラッシュできず、ExpressLRS 3.3.xのみがこれをサポートします。アプリは設定に基づいてファームウェアをビルドするため、STLinkまたはBetaflightパススルーを使用してPCからフラッシュできます。
-   **バイナリをダウンロード。**ビルドされたファームウェアファイルをフラッシュせずに保存し、手動フラッシュや監査のために使用します。
-   **ELRS Luaスクリプトをエクスポート。**EdgeTXおよびOpenTXラジオ用に`elrs.lua`を保存します。
-   **デバッグレポートを送信。**バグの修正に役立つように、デバイス情報とアプリログを送信します。バインディングフレーズとWi-Fiパスワードは決して含まれません。

## トラブルシューティング

**Dashboardがデバイスを見つけられません。**スマートフォンがまだデバイスのWi-Fiネットワークに接続されていることを確認してください。一部のスマートフォンはインターネットがないネットワークから切断されることがあります。Androidでは、ELRS MobileはインターネットがなくてもそのWi-Fiネットワーク上でトラフィックを維持します。**Retry**をタップするか、ギアアイコンからIPアドレス（デバイス自身のホットスポットでは`10.0.0.1`）を入力してください。

**ファームウェアをダウンロードできません。**デバイスのホットスポットから切断し、インターネットに接続されたネットワークを使用してください。

**フラッシュ失敗後、デバイスが反応しません。**USB経由で接続しながらBOOTボタンを押し続けると、ブートローダーモードに入ります。その後、[ExpressLRS Web Flasher](https://expresslrs.org/flasher)で再フラッシュしてください。Wi-Fi対応デバイスは、BOOTボタンを60秒間押し続けることでWi-Fiホットスポットを起動し、復旧することもできます。アプリ内の**Help & Support**画面には、これらの手順、FAQ、ExpressLRS Discordへのリンクがあります。

**アップデート後、プロファイルが消えました。**v1.0.43以前からv1.0.45以降へ直接アップデートする場合、ストレージのアップグレードにより、保存されたプロファイル、バインディングフレーズ、Wi-Fi設定を引き継ぐことができません。アプリが一度通知しますので、Settingsで再入力してください。
