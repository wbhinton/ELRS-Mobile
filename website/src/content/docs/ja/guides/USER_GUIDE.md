ELRS Mobileは、外出先でラップトップもインターネット接続も不要で、Wi-Fi経由でスマートフォンからExpressLRS受信機（RX）と送信機（TX）をフラッシュおよび設定できます。ESPベースのハードウェア（ESP8285、ESP32、ESP32-C3、ESP32-S3）とExpressLRS 3.3.xおよび4.xファームウェアに対応しています。すべての互換デバイスについては、[サポートされているハードウェア](/supported_hardware)をご覧ください。

ワークフローは2つの段階に分かれます。インターネット接続があるときにファームウェアをダウンロードし、その後はどこでもフラッシュできます。

ストア版はGoogle PlayおよびApp Storeを通じて更新されます。直接ダウンロードしたAPKは、1日に1回新しいリリースがないか確認し、ダウンロードを提案します。また、**設定 → 情報と法律 → 更新を確認** からいつでも確認したり、バージョンをスキップしたり、後で通知を受け取ることもできます。アップデートをインストールしても、設定とプロファイルは保持されます。

新しい機能をいち早く試したいですか？[Google Playベータ版](https://play.google.com/apps/testing/io.datarx.elrsmobile)または[TestFlightベータ版](https://testflight.apple.com/join/jwU1WrpX)にご参加ください。

初回起動時には、アプリが短い免責事項を表示します。ファームウェアのフラッシュは常にハードウェアに何らかのリスクを伴います。続行するにはこれに同意してください。

## クイックスタート: 初めてのデバイスをフラッシュする

### ステップ1: ファームウェアをダウンロードする（自宅で）

1.  ダッシュボードで、**ファームウェアマネージャー**を開きます。
2.  目的のExpressLRSバージョンの隣にあるダウンロードアイコンをタップします。バージョン3.3.0以降のみがリストされます。これらはELRS Mobileが構築する統合ファームウェアを初めて搭載したバージョンです。
3.  ダウンロードが完了すると、バージョンは**オフラインで使用可能**と表示されます。ファームウェアとそれが必要とするハードウェア定義が、これでスマートフォンに保存されました。

自宅のWi-Fiまたはモバイルデータを使用してファームウェアをダウンロードしてください。スマートフォンが受信機または送信機のWi-Fiホットスポットに接続されている間は、そのネットワークにインターネットがないためダウンロードできません。

ヘッダーには、制限に対して保存されているバージョン数が表示されます。**設定 → アプリとストレージ → キャッシュされた最大バージョン数** で制限を変更し、不要になったバージョンを削除してください。

### ステップ2: デバイスに接続する

1.  受信機または送信機の電源を入れ、Wi-Fiホットスポットが起動するのを待ちます。デフォルトでは、ペアと接続されていない場合、電源投入後60秒でホットスポットが起動します。送信機は、ラジオのExpressLRS LuaスクリプトからWi-Fiを起動することもできます。
2.  スマートフォンで、**ExpressLRS RX**または**ExpressLRS TX**ネットワークに接続します。パスワードは`expresslrs`です。
3.  ELRS Mobileを開きます。ダッシュボードが自動的にデバイスを検出し、その製品名、ファームウェアバージョン、ターゲット、および規制ドメインを表示します。

ダッシュボードに**デバイスが見つかりません**と表示された場合は、**再試行**をタップします。デバイスが別のネットワーク（たとえば、自宅のWi-Fiに接続されている場合）にある場合は、デバイスカードの歯車アイコンをタップし、そのIPアドレスを入力してください。

ファームウェアが3.1より古いデバイスも検出されるため、最新のリリースに更新できます。

### ステップ3: フラッシュ

1.  ダッシュボードで、**デバイスをフラッシュ**をタップします。
2.  ターゲットを確認します。可能な場合、アプリは接続されたデバイスに一致するターゲットを事前に選択します。そうでない場合は、デバイスの種類、デバイスベンダー、規制および周波数、デバイスターゲットを選択してください。
3.  ファームウェアのバージョンを選択します。ダウンロード済みのバージョンは**(キャッシュ済み)**と表示されます。ハードウェアが現在お持ちのバージョンよりも新しいバージョンを必要とする場合、アプリはそれを通知し、互換性のあるバージョンのダウンロードを提案します。
4.  ファームウェアのオプションを確認します: フラッシュプロファイル、バインドフレーズ、Wi-Fiネットワークとパスワード、規制ドメイン、Wi-Fi自動オン間隔。
5.  **フラッシュ**をタップします。

プログレスバーは各ステップ（ダウンロードされたファームウェアの特定と解凍、設定によるビルド、アップロード、そしてデバイスがインストールして再起動する間の**デバイスへの書き込み — お待ちください**）を追跡します。デバイスが確認すると、**フラッシュ成功！デバイスが再起動しています**と表示され、デバイスが起動し直すとダッシュボードが再接続します。

## 安全確認

アプリはフラッシュ前に選択内容を確認し、問題があるように見える場合は停止します。

:::danger[互換性のないチップ]
あるチップ用のファームウェアは、別のチップでは決して動作しません（例：ESP8285受信機でESP32ファームウェアを使用する場合）。アプリはフラッシュをブロックし、各チップがどれであるかを通知します。デバイスのチップに対応するターゲットを選択してください。
:::

:::caution[ターゲット不一致]
選択したターゲットがデバイスが報告する製品と一致しない場合、**ターゲット不一致**と表示されます。まず選択内容を確認してください。それが正しいと確信している場合（たとえば、誤ったフラッシュからの回復や新しいターゲット定義への移行など）、**強制フラッシュ**をタップします。
:::

:::note[バインドフレーズなし]
バインドフレーズなしでフラッシュすることも可能ですが、デバイスはデフォルト（空の）フレーズのみを使用してバインドされます。続行する前にアプリが確認します。
:::

:::caution[フラッシュ未確認]
デバイスがフラッシュを確認する前に切断された場合（電源が切れた、再起動した、またはWi-Fi接続が切断されたなど）、アプリはアップデートが完了したかどうかを判断できません。成功を報告する代わりに、オレンジ色の警告が表示されます。再接続してダッシュボードでファームウェアのバージョンを確認し、変更されていない場合は再度フラッシュしてください。
:::

## フラッシュプロファイル

フラッシュプロファイルは、バインドフレーズ、ホームWi-Fiネットワークとパスワード、デフォルトの規制ドメイン、Wi-Fi自動オン間隔を名前の下に保存します。フリートまたは無線設定ごとに1つを使用し、ワンタップで切り替えることができます。

**設定 → プロファイルとネットワーク** でプロファイルを管理します:

-   **追加:** **+**をタップし、名前を入力して**追加**をタップします。
-   **切り替え:** **フラッシュプロファイル**リストからプロファイルを選択します。これはフラッシュ画面でも利用できます。
-   **編集:** 任意のフィールドを変更します。アクティブなプロファイルは自動的に保存されます。
-   **削除:** プロファイルを選択し、削除アイコンをタップします。常に少なくとも1つのプロファイルが保持されます。

バインドフレーズとWi-Fiパスワードは、スマートフォンの暗号化された安全なストレージに保存されます。

## デバイス設定

ダッシュボードで**デバイス設定**をタップすると、接続されているデバイス自身のExpressLRS設定ページがアプリ内で開きます。これを使用して、Wi-Fiとバインドの設定、モデルマッチ、シリアルプロトコル、PWM出力マッピング、その他のデバイスオプションを変更できます。アプリはページをデバイスにロックします。

---

## 設定

| セクション | 内容 |
| :--- | :--- |
| プロファイルとネットワーク | フラッシュプロファイル、バインドフレーズ、ホームWi-Fiネットワークとパスワード、デフォルトの2.4 GHzおよびサブGHz規制ドメイン |
| アプリとストレージ | キャッシュされた最大バージョン数、ファームウェアマネージャー、ファームウェアキャッシュのクリア、アプリ言語、匿名使用状況分析（デフォルトでオン; **分析を共有**でオフにできます） |
| 詳細設定とデバッグ | エキスパートモードとそのツール（以下参照） |
| 情報と法律 | アプリバージョン、法的通知とライセンス、開発のサポート、直接ダウンロードAPKでの**更新を確認** |

アプリの言語は、設定またはトップバーの言語ボタンから変更できます。ELRS Mobileは18言語で利用可能です。

## エキスパートモード

**設定 → 詳細設定とデバッグ → エキスパートモード**をオンにすると、以下が解除されます:

-   **STM32ターゲット。** 古いSTM32ベースのハードウェアはWi-Fi経由でフラッシュできず、ExpressLRS 3.3.xのみがこれをサポートしています。アプリは設定を使用してファームウェアをビルドするため、STLinkまたはBetaflightパススルーを使用してPCからフラッシュできます。
-   **バイナリをダウンロード。** ビルドされたファームウェアファイルをフラッシュせずに保存し、手動フラッシュや監査に使用します。
-   **ELRS Luaスクリプトをエクスポート。** EdgeTXおよびOpenTXラジオ用に`elrs.lua`を保存します。
-   **デバッグレポートを送信。** デバイス情報とアプリログを送信して、バグの修正に役立てます。バインドフレーズとWi-Fiパスワードは決して含まれません。

## トラブルシューティング

**ダッシュボードがデバイスを見つけられません。** スマートフォンがデバイスのWi-Fiネットワークに接続されたままであることを確認してください。一部のスマートフォンはインターネットがないネットワークを離れることがあります。Androidでは、ELRS MobileはインターネットがなくてもそのWi-Fiネットワーク上でトラフィックを保持します。**再試行**をタップするか、歯車アイコンからIPアドレス（デバイス自身のホットスポットでは`10.0.0.1`）を入力してください。

**ファームウェアをダウンロードできません。** デバイスのホットスポットから切断し、インターネットに接続されたネットワークを使用してください。

**フラッシュ失敗後、デバイスが応答しなくなりました。** USB経由で接続しながらBOOTボタンを押し続けるとブートローダーモードに入り、その後[ExpressLRS Web Flasher](https://expresslrs.org/flasher)で再フラッシュしてください。Wi-Fi対応デバイスは、BOOTボタンを60秒間押し続けてWi-Fiホットスポットを起動することでも復旧できます。アプリ内の**ヘルプとサポート**画面には、これらの手順、FAQ、およびExpressLRS Discordへのリンクがあります。

**アップデート後、プロファイルが消えました。** v1.0.43以前からv1.0.45以降へ直接アップデートする場合、ストレージのアップグレードにより保存されたプロファイル、バインドフレーズ、Wi-Fi設定を引き継ぐことができません。アプリは一度通知します。設定でそれらを再入力してください。
