## Обзор
Это приложение предоставляет комплексный мобильный интерфейс для управления оборудованием ExpressLRS. Оно позволяет пользователям настраивать параметры приемника (RX) и передатчика (TX), сопоставлять выходы PWM и прошивать обновления микропрограммы непосредственно с мобильного устройства.

## 🚀 Быстрый старт: Прошивка вашего первого устройства

### Фаза 1: Кэширование прошивки (Сделайте это дома)
1. Откройте приложение и перейдите в **Firmware Manager**.
2. Нажмите значок загрузки рядом с последним стабильным релизом.
3. Приложение загрузит и безопасно кэширует необходимые определения целей и оборудования для использования в автономном режиме.

### Фаза 2: Подключение к вашему устройству
1. Включите ваш приемник ExpressLRS (RX) или передатчик (TX).
2. Подождите 60 секунд (или настроенный вами интервал), пока устройство не перейдет в режим точки доступа Wi-Fi (быстро мигающий светодиод).
3. Подключите Wi-Fi вашего телефона к сети **ExpressLRS RX** или **ExpressLRS TX** (Пароль: `expresslrs`).
4. Откройте приложение. Панель мониторинга автоматически просканирует сеть с помощью mDNS и подключится к устройству.

### Фаза 3: Прошивка
1. На Панели мониторинга выберите **Flash Device**.
2. **Выберите ваше оборудование:** Используйте каскадные выпадающие списки для выбора типа устройства (Device Type), производителя (Vendor), частоты (Frequency) и цели (Target).
3. **Настройте параметры и профили:** Выберите **Flashing Profile** (или нажмите кнопку **+**, чтобы добавить новый именованный профиль) для загрузки ваших учетных данных. Настройте фразу привязки (Binding Phrase), Wi-Fi SSID, пароль Wi-Fi, регуляторные домены и интервал автоматического включения Wi-Fi.
4. Нажмите **FLASH**. Приложение соберет бинарный файл локально и отправит его на устройство.

### 📋 Управление профилями прошивки
Если у вас есть несколько дронов или радиоустановок с различными требованиями к конфигурации (например, разные фразы привязки или регуляторные домены), вы можете использовать именованные **Flashing Profiles** для сохранения и переключения конфигураций:
* **Добавить профиль**: Нажмите значок **+** рядом с выпадающим списком "Flashing Profile", введите имя и нажмите "Добавить".
* **Автосохранение**: Любые изменения учетных данных активного профиля (фразы привязки, SSID, пароля, домена или интервала) сохраняются автоматически в режиме реального времени.
* **Переключение профилей**: Просто выберите профиль из выпадающего списка, чтобы мгновенно загрузить его сохраненные настройки.
* **Удалить профиль**: Чтобы очистить список, выберите профиль из выпадающего списка и нажмите значок корзины/удаления (для удаления профиля у вас должно быть не менее двух профилей).

## Технические детали

### Подключение и обнаружение
Приложение использует надежную многоступенчатую последовательность обнаружения для поиска вашего оборудования:
1. **Разрешение mDNS**: Основной метод. Приложение сканирует на наличие `elrs_rx.local` или `elrs_tx.local`.
2. **Резервный статический AP**: Если mDNS заблокирован, приложение проверяет официальный IP-адрес точки доступа ELRS (`10.0.0.1`).
3. **Ручное переопределение IP**: Для сложных сетей вы может�� вручную ввести IP-адрес в настройках.

**Принудительная привязка к сети**: Современные смартфоны часто отключают Wi-Fi соединения без интернета. ELRS Mobile включает нативный слой "Принудительной маршрутизации", который заставляет ОС оставаться подключенной к аппаратному соединению, обеспечивая 100% надежное обнаружение в полевых условиях.
