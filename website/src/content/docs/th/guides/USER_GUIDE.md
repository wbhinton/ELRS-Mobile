ELRS Mobile ใช้แฟลชและกำหนดค่าตัวรับ (RX) และตัวส่ง (TX) ExpressLRS จากโทรศัพท์ของคุณผ่าน Wi-Fi โดยไม่ต้องใช้แล็ปท็อปและไม่ต้องเชื่อมต่ออินเทอร์เน็ตที่หน้างาน รองรับฮาร์ดแวร์ที่ใช้ ESP (ESP8285, ESP32, ESP32-C3, ESP32-S3) และเฟิร์มแวร์ ExpressLRS เวอร์ชัน 3.3.x และ 4.x ดู [ฮาร์ดแวร์ที่รองรับ](/supported_hardware) สำหรับอุปกรณ์ที่ใช้งานร่วมกันได้ทั้งหมด

ขั้นตอนการทำงานแบ่งออกเป็นสองส่วน: ดาวน์โหลดเฟิร์มแวร์เมื่อคุณมีอินเทอร์เน็ต จากนั้นแฟลชได้ทุกที่

## เริ่มต้นอย่างรวดเร็ว: แฟลชอุปกรณ์เครื่องแรกของคุณ

### ขั้นตอนที่ 1: ดาวน์โหล��เฟิร์มแวร์ (ที่บ้าน)

1. บนหน้าแดชบอร์ด ให้เปิด **ตัวจัดการเฟิร์มแวร์**
2. แตะไอคอนดาวน์โหลดถัดจากเวอร์ชัน ExpressLRS ที่คุณต้องการ จะแสดงเฉพาะเวอร์ชัน 3.3.0 และใหม่กว่าเท่านั้น: ซึ่งเป็นเวอร์ชันแรกที่มีเฟิร์มแวร์แบบรวมที่ ELRS Mobile ใช้เป็นพื้นฐาน
3. เมื่อดาวน์โหลดเสร็จสิ้น เวอร์ชันจะแสดง **พร้อมใช้งานแบบออฟไลน์** เฟิร์มแวร์และข้อมูลจำเพาะของฮาร์ดแวร์ที่จำเป็นได้ถูกจัดเก็บไว้ในโทรศัพท์ของคุณแล้ว

ดาวน์โหลดเฟิร์มแวร์ด้วย Wi-Fi ที่บ้านหรือข้อมูลมือถือของคุณ คุณไม่สามารถดาวน์โหลดได้ในขณะที่โทรศัพท์ของค���ณเชื่อมต่อกับฮอตสปอต Wi-Fi ของตัวรับหรือตัวส่ง เนื่องจากเครือข่ายนั้นไม่มีอินเทอร์เน็ต

ส่วนหัวจะแสดงจำนวนเวอร์ชันที่คุณจัดเก็บไว้เทียบกับขีดจำกัด เปลี่ยนขีดจำกัดได้ที่ **การตั้งค่า → แอป & ที่เก็บข้อมูล → จำนวนเวอร์ชันที่แคชสูงสุด** และลบเวอร์ชันที่คุณไม่ต้องการอีกต่อไป

### ขั้นตอนที่ 2: เชื่อมต่อกับอุปกรณ์ของคุณ

1. เปิดเครื่องรับหรือเครื่องส่งของคุณและรอให้ฮอตสปอต Wi-Fi เริ่มทำงาน โดยค่าเริ่มต้นจะเกิดขึ้น 60 วินาทีหลังจากเปิดเครื่องหากยังไม่ได้เชื่อมต่อกับคู่ของมัน เครื่องส่งยังสามา���ถเริ่ม Wi-Fi ได้จากสคริปต์ ExpressLRS Lua บนวิทยุของคุณ
2. บนโทรศัพท์ของคุณ ให้เข้าร่วมเครือข่าย **ExpressLRS RX** หรือ **ExpressLRS TX** รหัสผ่านคือ `expresslrs`
3. เปิด ELRS Mobile แดชบอร์ดจะค้นหาอุปกรณ์โดยอัตโนมัติและแสดงชื่อผลิตภัณฑ์ เวอร์ชันเฟิร์มแวร์ เป้าหมาย และโดเมนกำกับดูแล

หากแดชบอร์ดแสดง **ไม่พบอุปกรณ์** ให้แตะ **ลองใหม่** หากอุปกรณ์ของคุณอยู่ในเครือข่ายอื่น (เช่น เชื่อมต่อกับ Wi-Fi ที่บ้านของคุณ) ให้แตะไอคอนรูปเฟืองบนการ์ดอุปกรณ์แล้วป้อนที่อยู่ IP

อุปกรณ์ที่ใช้เฟิร์มแวร์เก่ากว่า 3.1 ก็จะถูกตรวจพบด้วย ดังนั้นคุณจึงสามารถอัปเดตเป���นเวอร์ชันปัจจุบันได้

### ขั้นตอนที่ 3: แฟลช

1. บนแดชบอร์ด ให้แตะ **แฟลชอุปกรณ์**
2. ตรวจสอบเป้าหมาย แอปจะเลือกเป้าหมายที่ตรงกับอุปกรณ์ที่เชื่อมต่อล่วงหน้าเมื่อทำได้ มิฉะนั้น ให้เลือกประเภทอุปกรณ์ ผู้จำหน่ายอุปกรณ์ ข้อกำหนด & ความถี่ และเป้าหมายอุปกรณ์
3. เลือกเวอร์ชันเฟิร์มแวร์ เวอร์ชันที่คุณดาวน์โหลดจะถูกทำเครื่องหมาย **(แคชแล้ว)** หากฮาร์ดแวร์ต้องการเวอร์ชันใหม่กว่าที่คุณมี แอปจะแจ้งและเสนอให้ดาวน์โหลดเวอร์ชันที่เข้ากันได้
4. ตรวจสอบตัวเลือกเฟิร์มแวร์: โปรไฟล์การแฟลช, รหัสเชื่อมต่อ, เครือข่าย Wi-Fi และรหัสผ่าน, โดเมนกำกับดูแล และช่วงเวลาเปิด Wi-Fi อัตโนมัติ
5. แตะ **แฟลช**

แถบความคืบหน้าจะแสดงแต่ละขั้นตอน: การค้นหาและแตกไฟล์เฟิร์มแวร์ที่คุณดาวน์โหลด, การสร้างด้วยการตั้งค่าของคุณ, การอัปโหลด, และ **กำลังเขียนไปยังอุปกรณ์ — โปรดรอ** ในขณะที่อุปกรณ์กำลังติดตั้งและรีสตาร์ท เมื่ออุปกรณ์ยืนยันแล้ว คุณจะเห็น **แฟลชสำเร็จ! กำลังรีบูตอุปกรณ์** และแดชบอร์ดจะเชื่อมต่อใหม่เมื่ออุปกรณ์กลับมาทำงาน

## การตรวจสอบความปลอดภัย

แอปจะตรวจสอบตัวเลือกของคุณก่อนการแฟลช และจะหยุดหากมีสิ่งใดดูผิดปกติ

:::danger[ชิปไม่เข้ากัน]
เฟิร์มแวร์สำหรับชิปหนึ่งไม่สามารถทำงานบนชิปอื่นได้ (เช่น เฟิร์มแวร์ ESP32 บนตัวรับ ESP8285) แอปจะบล็อกการแฟลชและแจ้งให้คุณทราบว่าแต่ละชิปคืออะไร เลือกเป้าหมายสำหรับชิปของอุปกรณ์ของคุณ
:::

:::caution[เป้าหมายไม่ตรงกัน]
หากเป้าหมายที่เลือกไม่ตรงกับผลิตภัณฑ์ที่อุปกรณ์รายงาน คุณจะเห็น **เป้าหมายไม่ตรงกัน** ตรวจสอบการเลือกของคุณก่อน หากคุณแน่ใจว่าถูกต้อง (เช่น การกู้คืนจากการแฟลชที่ผิดพลาด หรือการย้ายไปยังคำจำกัดความเป้าหมายที่ใหม่กว่า) ให้แตะ **บังคับแฟลช**
:::

:::note[ไม่มีรหัสเชื่อมต่อ]
การแฟลชโดยไม่มีรหัสเชื่อมต่อจะทำงานได้ แต่อุปกรณ์จะเชื่อมต่อโดยใช้รหัสเริ่มต้น (ว่างเปล่า) เท่านั้น แอปจะถามก่อนดำเนินการต่อ
:::

:::caution[แฟลชไม่ได้รับการยืนยัน]
หากอุปกรณ์ตัดการเชื่อมต่อก่อนที่จะยืนยันการแฟลช (แบตเตอรี่หมด, รีสตาร์ท, หรือการเชื่อมต่อ Wi-Fi หลุด) แอปจะไม่สามารถบอกได้ว่าการอัปเดตเสร็จสมบูรณ์หรือไม่ โดยจะแสดงคำเตือนสีเหลืองอำพันแทนที่จะรายงานความสำเร็จ เชื่อมต่อใหม่และตรวจสอบเวอร์ชันเฟิร์มแวร์บนแดชบอร์ด หากยังไม่เปลี่ยนแปลง ให้แฟลชอีกครั้ง
:::

## โปรไฟล์การแฟลช

โปรไฟล์การแฟลชจะบันทึกรหัสเชื่อมต่อ, เครือข่าย Wi-Fi ที่บ้านและรหัสผ่าน, โดเมนกำกับดูแลเริ่มต้น และช่วงเวลาเปิด Wi-Fi อัตโนมัติภายใต้ชื่อหนึ่ง ใช้หนึ่งโปรไฟล์ต่อฝูงบินหรือการตั้งค่าวิทยุ และสลับระหว่างโปรไฟล์ได้ในแตะเดียว

จัดการโปรไฟล์ได้ที่ **การตั้งค่า → โปรไฟล์และเครือข่าย**:

- **เพิ่ม:** แตะ **+**, พิมพ์ชื่อ, แล้วแตะ **เพิ่ม**
- **สลับ:** เลือกโปรไฟล์จากรายการ **โปรไฟล์การแฟลช** นอกจากนี้ยังมีให้ใช้งานบนหน้าจอการแฟลชด้วย
- **แก้ไข:** เปลี่ยนฟิลด์ใดก็ได้; โปรไฟล์ที่ใช้งานอยู่จะบันทึกโดยอัตโนมัติ
- **��บ:** เลือกโปรไฟล์แล้วแตะไอคอนลบ คุณต้องมีอย่างน้อยหนึ่งโปรไฟล์เสมอ

รหัสเชื่อมต่อและรหัสผ่าน Wi-Fi จะถูกจัดเก็บในพื้นที่เก็บข้อมูลที่ปลอดภัยและเข้ารหัสของโทรศัพท์คุณ

## การตั้งค่าอุปกรณ์

บนแดชบอร์ด ให้แตะ **การตั้งค่าอุปกรณ์** เพื่อเปิดหน้าการตั้งค่า ExpressLRS ของอุปกรณ์ที่เชื่อมต่อภายในแอป ใช้เพื่อเปลี่ยนการตั้งค่า Wi-Fi และการเชื่อมต่อ, การจับคู่โมเดล, โปรโตคอลซีเรียล, การแมปเอาต์พุต PWM และตัวเลือกอุปกรณ์อื่นๆ แอปจะล็อกหน้านี้ไว้กับอุปกรณ์ของคุณ

## โหมดผู้เชี่ยวชาญ

เปิดใช้งาน **การตั้งค่า → ขั้นสูงและการแก้ไขข้อบกพร่อง → โหมดผู้เชี่ยวชาญ** เพื่อปลดล็อก:

- **เป้าหมาย STM32** ฮาร์ดแวร์ที่ใช้ STM32 รุ่นเก่าไม่สามารถแฟลชผ่าน Wi-Fi ได้ และมีเพียง ExpressLRS 3.3.x เท่านั้นที่รองรับ แอปจะสร้างเฟิร์มแวร์ด้วยการตั้งค่าของคุณ เพื่อให้คุณสามารถแฟลชจาก PC ด้วย STLink หรือ Betaflight passthrough
- **ดาวน์โหลดไบนารี** บันทึกไฟล์เฟิร์มแวร์ที่สร้างขึ้นแทนการแฟลช เพื่อการ��ฟลชด้วยตนเองหรือการตรวจสอบ
- **ส่งออกสคริปต์ ELRS Lua** บันทึก `elrs.lua` สำหรับวิทยุ EdgeTX และ OpenTX
- **ส่งรายงานการแก้ไขข้อบกพร่อง** ส่งข้อมูลอุปกรณ์และบันทึกของแอปเพื่อช่วยแก้ไขข้อผิดพลาด รหัสเชื่อมต่อและรหัสผ่าน Wi-Fi จะไม่ถูกรวมอยู่ด้วย

## การแก้ไขปัญหา

**แดชบอร์ดไม่พบอุปกรณ์ของฉัน** ตรวจสอบให้แน่ใจว่าโทรศัพท์ของคุณยังคงเชื่อมต่อกับเครือข่าย Wi-Fi ของอุปกรณ์อยู่; โทรศัพท์บางรุ่นอาจออกจากเครือข่ายที่ไม่มีอินเทอร์เน็ต บน Android, ELRS Mobile จะคงการรับส่งข้อมูลไว้บนเครือข่าย Wi-Fi นั้นแม้ไม่มีอินเทอร์เน็ต แตะ **ลองใหม���** หรือป้อนที่อยู่ IP จากไอคอนรูปเฟือง (`10.0.0.1` บนฮอตสปอตของอุปกรณ์เอง)

**ฉันไม่สามารถดาวน์โหลดเฟิร์มแวร์ได้** ยกเลิกการเชื่อมต่อจากฮอตสปอตของอุปกรณ์และใช้เครือข่ายที่มีอินเทอร์เน็ต

**อุปกรณ์ของฉันไม่ตอบสนองหลังจากแฟลชไม่สำเร็จ** กดปุ่ม BOOT ค้างไว้ในขณะที่เสียบสาย USB เพื่อเข้าสู่โหมด bootloader จากนั้นแฟลชใหม่ด้วย [ExpressLRS Web Flasher](https://expresslrs.org/flasher) อุปกรณ์ที่รองรับ Wi-Fi สามารถกู้คืนได้โดยการกด BOOT ค้างไว้ 60 วินาทีเพื่อเริ่มฮอตสปอต Wi-Fi หน้าจอ **วิธีใช้และการสนับสนุน** ในแอปมีขั้นตอนเหล่านี้ คำถามที่พบบ่อย และลิงก์ไปยัง ExpressLRS Discord

**โปรไฟล์ของฉันหายไปหลังจากอัปเดต** การอัปเดตโดยตรงจากเวอร์ชัน 1.0.43 หรือเก่ากว่าเป็นเวอร์ชัน 1.0.45 หรือใหม่กว่า ไม่สามารถถ่ายโอนโปรไฟล์ที่บันทึกไว้, รหัสเชื่อมต่อ และการตั้งค่า Wi-Fi ข้ามการอัปเกรดพื้นที่เก็บข้อมูลได้ แอปจะแจ้งให้คุณทราบครั้งหนึ่ง; โปรดป้อนข้อมูลเหล่านั้นใหม่ในการตั้งค่า
