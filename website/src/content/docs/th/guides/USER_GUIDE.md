ELRS Mobile แฟลชและกำหนดค่า ExpressLRS รีซีฟเวอร์ (RX) และเครื่องส่งสัญญาณ (TX) จากโทรศัพท์ของคุณ ผ่าน Wi-Fi โดยไม่ต้องใช้แล็ปท็อปและไม่ต้องเชื่อมต่ออินเทอร์เน็ตที่หน้างาน ใช้งานได้กับฮาร์ดแวร์ที่ใช้ ESP (ESP8285, ESP32, ESP32-C3, ESP32-S3) และเฟิร์มแวร์ ExpressLRS 3.3.x และ 4.x ดู [ฮาร์ดแวร์ที่รองรับ](/supported_hardware) สำหรับอุปกรณ์ที่เข้ากันได้ทุกรุ่น

ขั้นตอนการทำงานมีสองส่วน: ดาวน์โหลดเฟิร์มแวร์ในขณะที่คุณมีอินเทอร์เน็ต จากนั้นแฟลชได้ทุกที่

เวอร์ชันที่ดาวน์โหลดจากสโตร์จะอัปเดตผ่าน Google Play และ App Store ไฟล์ APK ที่ดาวน์โหลดโดยตรงจะตรวจสอบการอัปเดตใหม่วันละครั้งและเสนอให้ดาวน์โหลด คุณยังสามารถตรวจสอบได้ตลอดเวลาจาก **การตั้งค่า → เกี่ยวกับ & กฎหมาย → ตรวจสอบการอัปเดต**, ข้ามเวอร์ชัน หรือตั้งการแจ้งเตือนภายหลังได้ การตั้งค่าและโปรไฟล์ของคุณจะยังคงอยู่เมื่อคุณติดตั้งการอัปเดต

ต้องการฟีเจอร์ใหม่ก่อนใครหรือไม่? เข้าร่วม [เบต้าของ Google Play](https://play.google.com/apps/testing/io.datarx.elrsmobile) หรือ [เบต้าของ TestFlight](https://testflight.apple.com/join/jwU1WrpX)

เมื่อเปิดแอปครั้งแรก แอปจะแสดงข้อความปฏิเสธความรับผิดชอบสั้นๆ การแฟลชเฟิร์มแวร์มีความเสี่ยงต่อฮาร์ดแวร์ของคุณเสมอ; โปรดยอมรับเพื่อดำเนินการต่อ

## เริ่มต้นใช้งานอย่างรวดเร็ว: การแฟลชอุปกรณ์เครื่องแรกของคุณ

### ขั้นตอนที่ 1: ดาวน์โหลดเฟิร์มแวร์ (ที่บ้าน)

1. บนแดชบอร์ด เปิด **ตัวจัดการเฟิร์มแวร์**
2. แตะไอคอนดาวน์โหลดถัดจากเวอร์ชัน ExpressLRS ที่คุณต้องการ แสดงเฉพาะเวอร์ชัน 3.3.0 ขึ้นไปเท่านั้น: ซึ่งเป็นเวอร์ชันแรกที่มีเฟิร์มแวร์แบบรวมที่ ELRS Mobile ใช้เป็นพื้นฐาน
3. เมื่อดาวน์โหลดเสร็จสิ้น เวอร์ชันจะแสดง **พร้อมใช้งานแบบออฟไลน์** เฟิร์มแวร์และข้อมูลฮาร์ดแวร์ที่จำเป็นจะถูกเก็บไว้ในโทรศัพท์ของคุณแล้ว

ดาวน์โหลดเฟิร์มแวร์โดยใช้ Wi-Fi ที่บ้านหรือข้อมูลมือถือ คุณไม่สามารถดาวน์โหลดได้ในขณะที่โทรศัพท์ของคุณเชื่อมต่อกับฮอตสปอต Wi-Fi ของรีซีฟเวอร์หรือเครื่องส่งสัญญาณ เนื่องจากเครือข่ายนั้นไม่มีอินเทอร์เน็ต

ส่วนหัวจะแสดงจำนวนเวอร์ชันที่คุณจัดเก็บไว้เทียบกับขีดจำกัดของคุณ เปลี่ยนขีดจำกัดได้ที่ **การตั้งค่า → แอป & ที่เก็บข้อมูล → จำนวนเวอร์ชันที่แคชสูงสุด** และลบเวอร์ชันที่คุณไม่ต้องการอีกต่อไป

### ขั้นตอนที่ 2: เชื่อมต่อกับอุปกรณ์ของคุณ

1. เปิดเครื่องรีซีฟเวอร์หรือเครื่องส่งสัญญาณของคุณ และรอให้มันเริ่มฮอตสปอต Wi-Fi โดยปกติแล้วจะเกิดขึ้น 60 วินาทีหลังจากเปิดเครื่องหากยังไม่ได้เชื่อมต่อกับคู่ของมัน เครื่องส่งสัญญาณยังสามารถเริ่ม Wi-Fi ได้จากสคริปต์ ExpressLRS Lua บนวิทยุของคุณ
2. บนโทรศัพท์ของคุณ เข้าร่วมเครือข่าย **ExpressLRS RX** หรือ **ExpressLRS TX** รหัสผ่านคือ `expresslrs`
3. เปิด ELRS Mobile แดชบอร์ดจะค้นหาอุปกรณ์โดยอัตโนมัติและแสดงชื่อผลิตภัณฑ์, เวอร์ชันเฟิร์มแวร์, เป้าหมาย และโดเมนข้อบังคับ

หากแดชบอร์ดแสดง **ไม่พบอุปกรณ์**, ให้แตะ **ลองอีกครั้ง** หากอุปกรณ์ของคุณอยู่ในเครือข่ายอื่น (เช่น เชื่อมต่อกับ Wi-Fi ที่บ้านของคุณ) ให้แตะไอคอนรูปเฟืองบนการ์ดอุปกรณ์และป้อนที่อยู่ IP

อุปกรณ์ที่ใช้เฟิร์มแวร์เก่ากว่า 3.1 ก็สามารถตรวจพบได้เช่นกัน ดังนั้นคุณจึงสามารถอัปเดตให้เป็นเวอร์ชันปัจจุบันได้

### ขั้นตอนที่ 3: แฟลช

1. บนแดชบอร์ด แตะ **แฟลชอุปกรณ์**
2. ตรวจสอบเป้าหมาย แอปจะเลือกเป้าหมายที่ตรงกับอุปกรณ์ที่เชื่อมต่อได้โดยอัตโนมัติเมื่อทำได้; มิฉะนั้น ให้เลือกประเภทอุปกรณ์, ผู้จำหน่ายอุปกรณ์, ข้อบังคับและความถี่, และเป้าหมายอุปกรณ์
3. เลือกเวอร์ชันเฟิร์มแวร์ เวอร์ชันที่คุณดาวน์โหลดจะถูกทำเครื่องหมาย **(แคชแล้ว)** หากฮาร์ดแวร์ต้องการเวอร์ชันที่ใหม่กว่าที่คุณมี แอปจะแจ้งและเสนอให้ดาวน์โหลดเวอร์ชันที่เข้ากันได้
4. ตรวจสอบตัวเลือกเฟิร์มแวร์: โปรไฟล์การแฟลช, รหัสผูก (binding phrase), เครือข่าย Wi-Fi และรหัสผ่าน, โดเมนข้อบังคับ, และช่วงเวลาเปิด Wi-Fi อัตโนมัติ
5. แตะ **แฟลช**

แถบความคืบหน้าจะแสดงแต่ละขั้นตอน: การค้นหาและแตกไฟล์เฟิร์มแวร์ที่ดาวน์โหลดมา, การสร้างด้วยการตั้งค่าของคุณ, การอัปโหลด, และ **กำลังเขียนไปยังอุปกรณ์ — โปรดรอ** ในขณะที่อุปกรณ์ติดตั้งและรีสตาร์ท เมื่ออุปกรณ์ยืนยัน คุณจะเห็น **แฟลชสำเร็จ! อุปกรณ์กำลังรีบูต** และแดชบอร์ดจะเชื่อมต่อใหม่เมื่ออุปกรณ์กลับมาทำงาน

## การตรวจสอบความปลอดภัย

แอปจะตรวจสอบการเลือกของคุณก่อนที่จะแฟลช และจะหยุดหากมีสิ่งใดผิดปกติ

:::danger[ชิปไม่เข้ากัน]
เฟิร์มแวร์สำหรับชิปหนึ่งไม่สามารถทำงานบนอีกชิปหนึ่งได้ (เช่น เฟิร์มแวร์ ESP32 บนรีซีฟเวอร์ ESP8285) แอปจะบล็อกการแฟลชและแจ้งให้คุณทราบว่าแต่ละอันเป็นชิปอะไร เลือกเป้าหมายสำหรับชิปของอุปกรณ์ของคุณ
:::

:::caution[เป้าหมายไม่ตรงกัน]
หากเป้าหมายที่เลือกไม่ตรงกับผลิตภัณฑ์ที่อุปกรณ์รายงาน คุณจะเห็น **เป้าหมายไม่ตรงกัน** ตรวจสอบการเลือกของคุณก่อน หากคุณแน่ใจว่าถูกต้อง (เช่น กู้คืนจากการแฟลชที่ผิดพลาด หรือย้ายไปยังเป้าหมายใหม่) ให้แตะ **บังคับแฟลช**
:::

:::note[ไม่มีรหัสผูก]
การแฟลชโดยไม่มีรหัสผูกสามารถทำได้ แต่อุปกรณ์จะผูก (bind) โดยใช้รหัสผูกเริ่มต้น (ว่างเปล่า) เท่านั้น แอปจะถามก่อนดำเนินการต่อ
:::

:::caution[การแฟลชไม่ได้รับการยืนยัน]
หากอุปกรณ์หลุดการเชื่อมต่อก่อนที่จะยืนยันการแฟลช (อุปกรณ์ไฟดับ, รีสตาร์ท, หรือการเชื่อมต่อ Wi-Fi หลุด) แอปจะไม่สามารถบอกได้ว่าการอัปเดตเสร็จสมบูรณ์หรือไม่ จะแสดงคำเตือนสีอำพันแทนที่จะรายงานว่าสำเร็จ เชื่อมต่อใหม่และตรวจสอบเวอร์ชันเฟิร์มแวร์บนแดชบอร์ด; หากยังไม่เปลี่ยนแปลง ให้แฟลชอีกครั้ง
:::

## โปรไฟล์การแฟลช

โปรไฟล์การแฟลชจะบันทึกรหัสผูก, เครือข่าย Wi-Fi ที่บ้านและรหัสผ่าน, โดเมนข้อบังคับเริ่มต้น, และช่วงเวลาเปิด Wi-Fi อัตโนมัติภายใต้ชื่อหนึ่ง ใช้หนึ่งโปรไฟล์ต่อกลุ่มอุปกรณ์หรือการตั้งค่าวิทยุ และสลับระหว่างกันได้ในแตะเดียว

จัดการโปรไฟล์ได้ที่ **การตั้งค่า → โปรไฟล์ & เครือข่าย**:

- **เพิ่ม:** แตะ **+**, พิมพ์ชื่อ, แล้วแตะ **เพิ่ม**
- **สลับ:** เลือกโปรไฟล์จากรายการ **โปรไฟล์การแฟลช** นอกจากนี้ยังมีให้เลือกบนหน้าจอการแฟลชด้วย
- **แก้ไข:** เปลี่ยนฟิลด์ใดก็ได้; โปรไฟล์ที่ใช้งานอยู่จะถูกบันทึกโดยอัตโนมัติ
- **ลบ:** เลือกโปรไฟล์แล้วแตะไอคอนลบ คุณต้องมีอย่างน้อยหนึ่งโปรไฟล์เสมอ

รหัสผูกและรหัสผ่าน Wi-Fi จะถูกเก็บไว้ในการจัดเก็บที่ปลอดภัยและเข้ารหัสของโทรศัพท์คุณ

## การกำหนดค่าอุปกรณ์

บนแดชบอร์ด แตะ **การกำหนดค่าอุปกรณ์** เพื่อเปิดหน้าการตั้งค่า ExpressLRS ของอุปกรณ์ที่เชื่อมต่อภายในแอป ใช้เพื่อเปลี่ยนการตั้งค่า Wi-Fi และการผูก, การจับคู่โมเดล, โปรโตคอลซีเรียล, การแมปเอาต์พุต PWM และตัวเลือกอุปกรณ์อื่นๆ แอปจะล็อกหน้าไว้กับอุปกรณ์ของคุณ

## โหมดผู้เชี่ยวชาญ

เปิดใช้งาน **การตั้งค่า → ขั้นสูง & ดีบัก → โหมดผู้เชี่ยวชาญ** เพื่อปลดล็อก:

- **เป้าหมาย STM32** ฮาร์ดแวร์ที่ใช้ STM32 รุ่นเก่าไม่สามารถแฟลชผ่าน Wi-Fi ได้ และมีเพียง ExpressLRS 3.3.x เท่านั้นที่รองรับ แอปจะสร้างเฟิร์มแวร์ด้วยการตั้งค่าของคุณเพื่อให้คุณสามารถแฟลชได้จากพีซีด้วย STLink หรือ Betaflight passthrough
- **ดาวน์โหลดไบนารี** บันทึกไฟล์เฟิร์มแวร์ที่สร้างขึ้นแทนการแฟลช เพื่อใช้ในการแฟลชด้วยตนเองหรือตรวจสอบ
- **ส่งออกสคริปต์ ELRS Lua** บันทึก `elrs.lua` สำหรับวิทยุ EdgeTX และ OpenTX
- **ส่งรายงานดีบัก** ส่งข้อมูลอุปกรณ์และบันทึกของแอปเพื่อช่วยแก้ไขข้อผิดพลาด รหัสผูกและรหัสผ่าน Wi-Fi จะไม่ถูกรวมอยู่ด้วย

## การแก้ไขปัญหา

**แดชบอร์ดไม่พบอุปกรณ์ของฉัน** ตรวจสอบให้แน่ใจว่าโทรศัพท์ของคุณยังคงเชื่อมต่อกับเครือข่าย Wi-Fi ของอุปกรณ์; โทรศัพท์บางรุ่นอาจออกจากเครือข่ายที่ไม่มีอินเทอร์เน็ต บน Android, ELRS Mobile จะคงการรับส่งข้อมูลไว้บนเครือข่าย Wi-Fi นั้นแม้จะไม่มีอินเทอร์เน็ต แตะ **ลองอีกครั้ง**, หรือป้อนที่อยู่ IP จากไอคอนรูปเฟือง (`10.0.0.1` บนฮอตสปอตของอุปกรณ์)

**ฉันไม่สามารถดาวน์โหลดเฟิร์มแวร์ได้** ยกเลิกการเชื่อมต่อจากฮอตสปอตของอุปกรณ์และใช้เครือข่ายที่มีอินเทอร์เน็ต

**อุปกรณ์ของฉันไม่ตอบสนองหลังจากแฟลชล้มเหลว** กดปุ่ม BOOT ค้างไว้พร้อมเสียบสาย USB เพื่อเข้าสู่โหมด bootloader จากนั้นแฟลชใหม่ด้วย [ExpressLRS Web Flasher](https://expresslrs.org/flasher) อุปกรณ์ที่รองรับ Wi-Fi สามารถกู้คืนได้โดยการกด BOOT ค้างไว้ 60 วินาทีเพื่อเริ่มฮอตสปอต Wi-Fi หน้าจอ **ความช่วยเหลือ & การสนับสนุน** ในแอปมีขั้นตอนเหล่านี้, คำถามที่พบบ่อย (FAQ) และลิงก์ไปยัง ExpressLRS Discord

**โปรไฟล์ของฉันหายไปหลังจากการอัปเดต** การอัปเดตโดยตรงจากเวอร์ชัน 1.0.43 หรือเก่ากว่าเป็นเวอร์ชัน 1.0.45 หรือใหม่กว่า ไม่สามารถถ่ายโอนโปรไฟล์ที่บันทึกไว้, รหัสผูก และการตั้งค่า Wi-Fi ข้ามการอัปเกรดที่เก็บข้อมูลได้ แอปจะแจ้งให้คุณทราบครั้งเดียว; โปรดป้อนข้อมูลเหล่านั้นอีกครั้งในการตั้งค่า
