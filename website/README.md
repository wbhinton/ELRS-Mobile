# elrsmobile.com

Astro + Starlight site for ELRS Mobile. Every page (landing, privacy, docs) renders
through Starlight, so the header, footer, `<head>`, search, and language picker
are shared. Hosting is Cloudflare, which builds from GitHub on push.

```sh
npm install
npm run dev          # http://localhost:4321 (restart after editing tailwind.config.mjs)
npm run build        # dist/
npm run check:links  # after a build: fail on broken internal links
```

## Where things live

Every fact has one home. Change it there and every page picks it up.

| What | Where |
|---|---|
| Languages | `src/config/locales.json` (Starlight locales, `[lang]` routes, translation script) |
| External URLs, analytics ID | `src/config/site.ts` |
| UI copy (all languages) | `src/i18n/ui.json`, read through `useTranslations(lang)` in `src/i18n/index.ts` |
| Brand colours | `tailwind.config.mjs` (also drives Starlight's `--sl-color-*` via `@astrojs/starlight-tailwind`) |
| Landing page content (steps, features, videos, stores, install options) | `src/data/landing.ts` |
| Install count | `src/data/usage.json` (edit by hand from analytics) |
| Supported hardware | `../assets/targets.json`, the copy the app bundles (auto-updated by `.github/workflows/update_targets.yml`) |
| Verified hardware, total flashes | `src/data/verified.json`, generated by `scripts/build_verified.py` |
| Docs sidebar groups, which docs are translated | `src/config/docs.json` |
| Docs | `src/content/docs/guides/` (English), `src/content/docs/<lang>/guides/` (translations) |
| Starlight overrides (header, footer, dark-only theme) | `src/components/starlight/` |
| Landing page components | `src/components/landing/` |

## Common tasks

**Update the install count.** Edit `installs` and `asOf` in `src/data/usage.json`.
Public figures are rounded down (38,422 shows as "38,000+").

**Refresh verified hardware and the flash total.** Export the per-target flash
counts from analytics as CSV (`hardware_target,successful_flashes,first_flash,last_flash`), then:

```sh
python3 website/scripts/build_verified.py path/to/verified_hardware.csv
```

A target is verified after one successful flash. Names must match `product_name`
in `assets/targets.json`; `npm run dev` logs any that don't.

**Update app screenshots.** Replace the iPhone store screenshots in
`store_front/apple/English (en-US)/iPhones  6.9/`, then run
`python3 website/scripts/crop_store_screenshots.py`.

**Add a language.** Add it to `src/config/locales.json`, then run the translation
workflow. Untranslated strings fall back to English.

**Add a video, feature, or install option.** Add an entry to `src/data/landing.ts`
and any new strings (English) to `ui.json`.

**Add a doc.** Create it in `src/content/docs/guides/` with a `slug`, and add the
slug to a group in `src/config/docs.json`.

**Track a link in analytics.** Add `data-track="<event>"` plus any `data-<param>`
attributes; one delegated listener (in `astro.config.mjs`) sends the event.

## Translation

`scripts/translate_astro.cjs` translates new or changed `ui.json` strings and docs
with Gemini. It costs money and is run manually (the `translate.yml` workflow or
`./scripts/translate.sh`). Never execute it to test it; use
`node --check scripts/translate_astro.cjs`. It skips docs in groups with
`"translate": false` and removes strings deleted from English.
